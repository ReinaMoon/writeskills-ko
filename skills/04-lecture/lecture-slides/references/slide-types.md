# 슬라이드 유형 (역할)

T 코드와 1:1로 쓸 수 있다. 도구별 레이아웃은 런타임 어댑터가 담당한다.

| 유형 | T | 구성 |
|------|---|------|
| 표지 | T-0 | 제목, 부제, 강사, 일시 |
| 섹션 | T-S | 번호 + 꼭지 제목 + 프리뷰 |
| 3카드 | T-1 | 병렬 3항 |
| 비교 | T-2 | 2열 Before/After 등 |
| 프로세스 | T-3 | 3~4 STEP |
| 목록 | T-4 | 세로 1~5 |
| 대비 | T-5 | 2안 강조 |
| 실습 | (없음) | 과제, 조건, 시간, 힌트 |
| 체크포인트 | (없음) | 질문, 선택지 |
| 요약 | T-Sum | Ch 핵심 + Next |
| 마무리 | T-Fin | 전체 요약 + Q&A |

배분 가이드(모듈): 20분 8~12장 / 30분 12~16장 / 40분 16~22장. 실습 모듈은 장수↓.
