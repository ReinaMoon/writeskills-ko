# T-유형 매칭 (플랫폼 중립)

특정 브랜드 템플릿에 묶이지 않는 **역할 코드**다. 조판 도구가 다르면 동일 역할로 매핑한다.

| T | 역할 | 쓸 때 |
|---|------|------|
| T-0 | 표지 | 시작 |
| T-S | 섹션 | Ch 시작 |
| T-1 | 3항 병렬 | 항목 3개 |
| T-2 | 2열 비교 | Before/After, 대등 비교 |
| T-3 | 단계 | 3~4 STEP, 프로세스 |
| T-4 | 세로 목록 | 1~5 체크, 순서 |
| T-5 | 대비 강조 | 2안 중 한쪽 강조 |
| T-Sum | Ch 요약 | 꼭지 마무리 |
| T-Fin | 전체 마무리 | Q&A, 요약 |

배치: `T-0 > (T-S > 본문 > T-Sum?)… > T-Fin`. 본문은 T-1~T-5를 3종 이상 섞는다. 같은 T 연속 3장 금지.
