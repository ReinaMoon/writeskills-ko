# 리뷰 점검 축

| 축 | 보는 것 |
|----|---------|
| 0 타깃 | 용어, 사전지식, 사례 접점, 실습 난이도, 학습목표 도달 |
| 0.5 BP 반영 | 제목, 메시지, T, 시각 힌트, 증거 (BP 있을 때만). 90%+ 통과 / 70~89 경고 / <70 실패 |
| 1 구조 | 도입-전개-마무리, 섹션 전환, 목표 커버, 중복, 누락, 난이도 곡선 |
| 2 분량 | 1~2분/장, 모듈 편차, 실습 30~50%, 60분+ 휴식 |
| 3 텍스트 | 1장1메시지, 행동형 제목, 과다 텍스트, 금지어, 어미 |
| 4 시각 | 다이어그램 적소, 품질, 플레이스홀더, 레이아웃 일관, 여백 |
| 5 발표 | 전환 멘트, 참여 리듬, 훅, 마무리 |

우선순위: 높음 = 목표 누락, 구조 붕괴, 금지어, BP <70%. 보통 = 시각, 분량, BP 편차. 낮음 = 문체, 노트.
