# 예시: 강의 덱 리뷰 점수표

대상: `SS_배포체크_20261110.md` (18장) / BP 있음

| 축 | 점수(1–5) | 메모 |
|----|----------:|------|
| 흐름 | 4 | 도입→체크→실습 순서 OK |
| 분량 | 3 | 중반 텍스트 장 3장 연속 |
| 메시지 1장 1개 | 5 | BP 반영률 제목, 메시지 90% |
| 시각 | 2 | 차트 장 0, 표만 2 |
| 발표 전환 | 4 | 실습 전 전환 멘트 있음 |

## 수정 목록 (우선)

1. 장 9–11 텍스트 장 → 1장은 체크리스트 표, 1장은 다이어그램 후보
2. BP 시각 ID C1 미반영 → 장 7에 에러율 차트 슬롯 추가
3. 장 18 요약이 새 개념 도입 → 삭제하고 3요점만

반영률 재측정 목표: 시각 ≥ 70%.
