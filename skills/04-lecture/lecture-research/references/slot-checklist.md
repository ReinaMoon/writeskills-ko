# 강의 슬롯 체크리스트

스키마 정본: `../../../00-core/handoff/research-card-schema.md` (lecture).

| 슬롯 | 필수 포인트 |
|-----:|-------------|
| 1 도입 훅 | 질문/사례/대비/인용 중 하나 + 슬롯2 연결 1줄 |
| 2 핵심 개념 | 1~2줄, 행동, 결과 중심 |
| 3 데이터 | 3개+, 카테고리(시장, 사용, 비용, 시간) 2종+, 등급, 시점, 활용 1줄 |
| 4 대표 사례 | 최대 3, A/B 합 2+, 요약+출처+메시지 |
| 5 본인 사례 | 상황, 한 일, 결과. 없으면 사유 |
| 6 비교 매트릭스 | 해당 시. 아니면 N/A |
| 7 반박, 응답 | 2개+ |
| 8 실습 | 시간, 재료, 검증 메시지(어느 슬롯 검증인지) |
| 9 수준별 | 초/중/고 한 줄씩 |
| 10 시각 | 이미지, 도식, 차트 ID (`I#`/`G#`/`C#`), 라이선스 메모 |
| 11 구술 | 도입 / 전환 2~4 / 마무리 |
| 12 흐름 | 도입>전개>절정>정리, 분 합 = 꼭지 시간 |

시각화 표기: `V-CHART` / `V-DIAGRAM` / `V-IMAGE` / `V-TABLE` / `V-TEXT`.
