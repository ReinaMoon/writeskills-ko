# 썸네일, OG 유형 참조

`image-content` 썸네일 모드에서 로딩한다.

## 유형 4

| 코드 | 이름 | 적합 |
|------|------|------|
| A | 아이콘 중심 | 도구, 기능, 개념 소개 |
| B | 장면 | 경험담, 과정, 실수 사례 |
| C | 타이포 중심 | 선언, 숫자, 짧은 메시지 |
| D | 분할 비교 | Before/After, A vs B |

추천: 비교 신호 > D, 강한 한 문장 > C, 인물 행동 > B, 그 외 > A.

## 4색 역할

| 역할 | 용도 |
|------|------|
| 배경 | 전체 바탕, 큰 블롭 |
| 메인 | 캐릭터, 주 오브젝트 |
| 강조 | 하이라이트 10~15% |
| 텍스트 | 카피, 레이블 |

### 톤 > 팔레트 제안 (브랜드 없을 때)

| 톤 | 배경 / 메인 / 강조 / 텍스트 |
|----|------------------------------|
| 정보, 도구 (기본) | `#E8F0FE` / `#1A73E8` / `#FBBC04` / `#202124` |
| 비교, 분석 | `#ECEFF1` / `#455A64` / `#1A73E8` / `#263238` |
| 팁, 발견 | `#FFFDE7` / `#F9A825` / `#1A73E8` / `#F57F17` |
| 경고, 실수 | `#FBE9E7` / `#D32F2F` / `#FFA726` / `#B71C1C` |
| 교육, 성장 | `#E6F4EA` / `#1E8E3E` / `#FDD835` / `#1B5E20` |

브랜드 HEX가 있으면 역할만 매핑해 교체한다.

## 텍스트 배치 T1~T5

| 코드 | 방식 | 1순위 유형 |
|------|------|------------|
| T1 | 배경 위 직접 | C, A |
| T2 | 말풍선 | B |
| T3 | 색 블록 위 흰 글자 | A, D |
| T4 | 작은 레이블 | A, D |
| T5 | 텍스트 없음 | 이미지 자체가 메시지일 때 |

길이: 메인 ≤10자, 서브 ≤15자, 말풍선, 레이블 ≤8자. 
맥락 키워드(제품, 대상명)를 메인 또는 서브에 1개 이상.

## 프롬프트 골격

```text
[용도] 블로그/OG 썸네일 {유형} 일러스트를 생성해줘.
[구도] …
[레이어] 배경(단색+단순 패턴) → 메인 → 텍스트 → 보조 장식(최소)
[팔레트] 배경 #, 메인 #, 강조 #, 텍스트 #
[스타일] 라인+플랫 컬러, 과한 입체, 네온 금지
[비율] 16:9 (또는 사용자 지정)
[텍스트] 배치 T? + 실제 문자열
```

밀도 체크(3~4개면 충분): 텍스트 또는 T5, 배경 레이어, 핵심 오브젝트, 보조 장식은 최소.

## 캐릭터 (B, D 선택)

- **크리에이터형**: 캐주얼, 노트북, 노트 
- **비즈니스형**: 셔츠, 모니터, 차트 

공통: 심플 일러스트 + 메인색 의상 + 동작, 표정 명시. 등신, 픽셀 수치는 넣지 않는다.
