# 인포그래픽 레이아웃, 컬러 참조

`image-content` 인포 모드에서 로딩한다.

## 유형 3

| 유형 | 신호 | 중앙 내용 |
|------|------|-----------|
| 요약 | 포인트, 원칙 나열 | 아이콘+키워드 3~5 |
| 구조 | 비교, 분류, 관계 | 매트릭스, 계층, 관계도 |
| 프로세스 | 순서, 워크플로 | 좌>우 단계 |

## 레이아웃 L1~L5

| 코드 | 이름 | 적합 |
|------|------|------|
| L1 | 중앙 집중 | 단일 정의, 한 메시지 |
| L2 | 좌우 2분할 | 장단점, Before/After |
| L3 | 카드 그리드 2×2 | 특징, 사례 4개 |
| L4 | 가로 타임라인 | 로드맵, 단계 |
| L5 | 방사형 | 허브-스포크, 생태계 |

### 강조 패널 (선택)

| 코드 | 구조 | 언제 |
|------|------|------|
| EP-A | 상단 본문 + 하단 강조 띠 | 결론 한 줄이 있을 때 |
| EP-B | 좌 본문 + 우 사이드 강조 | 큰 숫자, 키워드 분리 |

추천 출력 기본: EP-A, EP-B, 표준 L 단독(시리즈 일관성용).

## 컬러 키 (성격 매칭)

배경 흰(`#FFFFFF`) 고정. 포인트만 메인, 보조.

| 성격 | 메인 | 보조 |
|------|------|------|
| 교육, 일반 기본 | `#1E3A8A` | `#60A5FA` |
| 공공, 기관 | `#065F46` | `#6EE7B7` |
| IT, 테크 | `#374151` | `#F59E0B` |
| 크리에이티브 | `#6D28D9` | `#F472B6` |
| 의료 | `#0F766E` | `#5EEAD4` |
| 금융, 컨설팅 | `#1E3A8A` | `#D4A574` |

사용자 HEX, 프리셋이 있으면 덮어쓴다. 배치 생성 전 팔레트 1회 확인(단건은 생략 가능).

## 시각 장치 (0~2개)

- 강조 배지, 연결선/화살표, 데이터(큰 숫자) 
수치 신호 > 데이터, 관계 신호 > 연결선, 키워드 ≤3 > 배지.

## 프롬프트 4섹션 체크

1. 유형+레이아웃 한 줄 
2. **표시 텍스트만** (메인 타이틀, 카드 인덱스, 제목, 캡션) 
3. **디자인 사양** (이미지에 쓰지 말 것): 여백 generous, 헤어라인, 카드 동일 밀도, 스틱맨은 필요할 때만, 상대 크기 표현 
4. **렌더 가드**: px/pt/HEX/폰트명/영문 매거진 헤더를 화면에 그리지 말 것. 섹션 2의 한글만 허용.

지시 수준: “가로 균등”, “얇은 구분선” O, `8px`, `border-radius:12px` X.

## 길이, 항목

| 항목 수 | 권장 |
|--------:|------|
| 3~4 | 안정 |
| 5~6 | 캡션 축소 |
| 7+ | 2장으로 분리 |

연속 배치 시 동일 레이아웃 3회 연속 금지(변형, EP로 리듬).
