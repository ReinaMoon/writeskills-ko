# 삽화 유형, 구도 참조

`image-book` 삽화 모드에서 로딩한다.

## 라인 vs 인포

| 단서 | 라인 드로잉 | 인포그래픽 |
|------|-------------|------------|
| 원고 | 시간, 장소, 행동, 감정 | 표, 단계, 비교, 체계 |
| 독자 반응 | 공감, 몰입 | 이해, 정리 |
| 결론부 | 감상, 깨달음 | 기준, 구조 |

한 권에서 두 유형을 섞을 수 있다. 서사 Part는 라인, 체계 Part는 인포.

## 라인 구도 3

| 구도 | 언제 | 구성 |
|------|------|------|
| 좌우 대칭 | A>B 상태 전환 | 좌 Before / 중 전환 / 우 After |
| 중앙 집중 | 한 사람의 판단 | 중앙 인물 + 방사 요소 |
| 시간 흐름 | 3단 이상 과정 | 장면1>2>3 |

기본값: 좌우 대칭.

## 인포 세부 6 (결정 트리)

1. Before/After, A vs B > **비교형**
2. 순차 행위 단계 > **프로세스형**
3. 끝이 다시 시작 > **순환형**
4. 기반/표면, 상위/하위 > **계층형**
5. 시점 변화(과거>현재) > **타임라인형**
6. 1>N 분류 > **구조형** (아니면 비교형을 기본)

프로세스 = “무엇을 하는가”, 타임라인 = “언제 바뀌었는가”.

### 3분할 (비교, 프로세스, 타임라인, 구조)

좌 40%, 중앙 전환 20%, 우 40%. 중앙 장치: 점선, 화살표, 시계, 격자 등.

### 전용

- **계층형**: 하단 기반 / 상단 표면, 수직 연결
- **순환형**: 4분면 시계방향 + 중앙 아이콘

## 시리즈 일관성

| 축 | 규칙 |
|----|------|
| 스타일 | 첫 장의 선 굵기, 도형 언어를 전체에 복사 |
| 색 | 라인=흑백. 인포=주조 1색 고정 + 파트 보조색만 변경 |
| 캐릭터/아이콘 | 비율, 머리 크기, 아이콘 세트를 첫 회에 고정 |
| 비율 | 시리즈 통일 (기본 16:9 가로, 사용자 지정 가능) |
| 배경 | 흰 단색 기본 (`#FFFFFF`) |
| 텍스트 | 핵심 키워드만. 장문 금지 |

## 장르 기본 팔레트 (인포 제안용)

| 장르 | 주조 | 보조 예 |
|------|------|---------|
| 실용서 | `#1B2A4A` | 청록, 앰버, 슬레이트 |
| 에세이 | `#5C5C5C` | 코랄, 세이지 |
| IT | `#2D2D2D` | 블루, 민트 |
| 교육 | `#1E3A8A` | 스카이, 앰버 |

삽화 1장당 색 3개 이하(주조+보조+배경).

## 챕터 프롬프트 3섹션

1. 기본: 핵심, 시각화 포인트, 상태 변화 또는 유형 근거 
2. 구도: 영역별 구체 요소 
3. 공통: 분위기, 금지, 비율, 시리즈 스타일 참조 

수정은 섹션 단위. 3~5안 생성 후 1안 선별을 권장 문구로만 안내한다(도구 강제 없음).
