# 장르 문법, 표지 프롬프트 참조

`image-book` 표지 모드 Step에서 로딩한다. 벤더 전용 문법은 없다.

## 장르별 신호 (요약)

| 장르 | 색감 경향 | 구도 | 타이포 |
|------|-----------|------|--------|
| 실용서, 비즈니스 | 블루, 네이비, 화이트 / 네이비+골드 | 아이콘, 도식, 여백 | 큰 산세리프 제목 |
| 자기계발 | 따뜻함(주황, 파스텔) | 인물, 상징 | 감성 카피 + 이름 영역 |
| IT, 테크 | 딥블루, 다크, 포인트 1색 | 추상, 패턴, 키워드 | 굵은 산세리프 |
| 에세이, 경험 | 톤다운(감색, 베이지, 크림) | 넓은 여백+작은 심볼 | 호흡 있는 세리프/손글씨 계열 |
| 교육, 학습 | 구조적 2~3색 | 명확한 정보 레이아웃 | 가독 우선 |
| 소설, 문학 | 장르별 대비 또는 단색 | 단일 분위기 이미지 | 제목이 주인공(세리프) |
| 시집, 산문 | 1~2색 절제 | 최소 요소, 여백 | 손글씨/세리프 |
| 라이프, 요리 | 웜 아이보리+피사체색 | 사진, 전면 비주얼 | 부제로 설명 |
| 아동 | 고채도 다색 | 캐릭터 전면 | 둥근 친근 폰트 |

교차 장르: **서가에 놓일 1차 장르**로 문법을 잡고, 톤은 실제 성격 장르를 따른다.

## 3색 세트 예시 (주조 / 보조 / 배경)

사용자가 지정하지 않을 때만 제안한다. HEX는 출발점이며 브랜드 팔레트가 있으면 교체한다.

|------|---|---|
| 실용서 | `#3366CC` / `#F5A623` / `#FFFFFF` | `#1B2A4A` / `#C8A96E` / `#F7F4EF` |
| IT | `#1A237E` / `#00E676` / `#0D1117` | `#3F51B5` / `#E0E0E0` / `#FFFFFF` |
| 에세이 | `#2C3E6B` / `#C8A96E` / `#F5E6D0` | `#4A5568` / `#D69E2E` / `#FFFDF7` |
| 소설 | `#1A1A1A` / `#C0392B` / `#F5F0EB` | `#2C3E50` / `#E8D5B7` / `#FFFFFF` |
| 교육 | `#4A7BD6` / `#FF7043` / `#FFFFFF` | `#00897B` / `#FFB300` / `#F5F5F5` |

## 키 비주얼 7항목

프롬프트 [블록 4]에 빠짐없이 쓴다.

1. 오브젝트 2. 개수, 관계 3. 크기, 비율 4. 위치 5. 시선 방향 6. 디테일 수준 7. 질감, 재질

## 6블록 작성 팁

- [2] 부정 표현 허용 (“차가움이 아니라 따뜻한 전문성”).
- [3] 3색만. 네 번째 색은 하이라이트 금지 기본.
- [4] 텍스트 영역(“상단 1/3 제목”)을 이미지 요소와 분리해 적는다.
- [6] 비율 기본 **2:3**(종이책형). 전자책 정사각, 와이드는 사용자 지정 시만.
- 수정 시 전체 재작성 금지. 변경된 블록만 교체 문구로 제시.

## 선별, 완성 체크

| 항목 | 질문 |
|------|------|
| 메시지 | 3초 안에 핵심이 느껴지는가 |
| 장르 | 서가 카테고리가 읽히는가 |
| 축소 | 작은 썸네일에서도 제목이 보이는가 |
| 차별 | 같은 서가에 묻히지 않는가 |
