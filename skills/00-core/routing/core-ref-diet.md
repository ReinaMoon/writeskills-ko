# 코어 참조 다이어트

`SKILL.md`의 코어 링크는 **필수 2~3개 + 선택**만 적습니다. 전체 목록을 매번 붙이지 않습니다.

## 카테고리별 필수

| 카테고리 | 필수 (항상) | 자주 쓰는 선택 |
|----------|-------------|----------------|
| 01-writing | `mystyle-gate`, `writing-principles`, `tone-matrix` | `korean-prose-rules`, `quality-gates` |
| 02-book / 03-novel | `pipeline-convention`, `handoff-schema`, `writing-principles` | `research-card-schema`, `mystyle-gate`, `quality-gates` |
| 04-lecture | `pipeline-convention`, `research-card-schema`, `output-rules` | `runtime-files`, `quality-gates` |
| 05-research | `research-card-schema`, `writing-principles` | `output-rules`, `vault-obsidian` |
| 06-wiki | `wiki-page-schema`, `pipeline-convention` | `vault-obsidian`, `quality-gates` |
| 07-bizplan | `research-card-schema`, `pipeline-convention`, `writing-principles` | `runtime-files`, `output-rules` |
| 08-it-docs | `tone-matrix`, `korean-prose-rules`, `quality-gates` | `output-rules`, `writing-principles` |
| 09-image | `output-rules`, `runtime-files` | `quality-gates`, `writing-principles` |

`trigger-map.md`는 description 작성, 충돌 시에만 링크합니다. 매 실행 필수가 아닙니다.

## 본문 표기 예

```markdown
## 코어 참조

필수:
- `../../00-core/style/mystyle-gate.md`
- `../../00-core/principles/writing-principles.md`
- `../../00-core/style/tone-matrix.md`

선택: `korean-prose-rules`, `quality-gates` (퇴고 시)
```
