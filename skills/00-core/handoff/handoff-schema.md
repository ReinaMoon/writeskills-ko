# 인계 스키마

기획 > 리서치 > 집필(또는 조판)로 넘기는 **고정 슬롯 블록**입니다. 
책 체인이 원형이며, 강의, 사업계획은 프로필만 바꿔 같은 번호를 재사용합니다.

파일명 기본: `00-handoff.md` 
슬롯 번호는 후속 스킬이 참조하는 고정값입니다. 삭제, 재번호 금지. 빈 값은 `[미정]`.

---

## 공통 frontmatter

```yaml
---
project: "{제목}"
pipeline: book | lecture | bizplan | novel
created: YYYY-MM-DD
updated: YYYY-MM-DD
source_skill: "{예: book-planning}"
source_phase: "{시작}~{끝}"
---
```

## A. 책, 실용서 프로필 (`pipeline: book`)

```markdown
# 기획 인계: {책 제목}

## 슬롯 0. 프로젝트 기본 정보

| 항목 | 값 |
|------|-----|
| 가제 | |
| 장르, 형식 | 실용서 / 가이드 / 핸드북 / 에세이 논픽션 |
| 예상 분량 | N장 / 원고 분량 |
| 종결어미 | 합니다 / 다 |
| 출처 표기 | 국내 관행 / APA / Chicago / 간략 / 미정 |
| 기획서 용도 | 출판 제안 / 자가출판 / 내부 |

## 슬롯 1. 콘셉트

- **한 문장 콘셉트:**
- **차별점:**
- **읽은 뒤 변화:**
- **쓰지 않을 것:**

## 슬롯 2. 독자 프로필

| 구분 | 내용 |
|------|------|
| 핵심 독자 | (상황, 동기까지) |
| 확장 독자 | |
| 현재 수준 | |
| 기대 수준 | |
| 반복 질문 | 2~3개 |

## 슬롯 3. 목차

(파트 포함. 챕터 번호 2자리)

## 슬롯 4. 챕터별 개요

### Ch01 {제목}
- 핵심 논점:
- 소제목: (3~5)
- 핵심 소재:
- 앞뒤 연결:

## 슬롯 5. 경험 소재 요청

| Ch | 삽입 지점 | 필요한 경험 | 상태 |
|----|----------|-------------|------|
| 01 | | | [소재 필요] |

## 슬롯 6. 리서치 요청

| Ch | 확인이 필요한 것 | 자료 유형 | 우선순위 |
|----|-----------------|----------|---------|
| 01 | | 통계 / 사례 / 논문 / 반론 | 상/중/하 |
```

작성 규칙:

- 슬롯 0의 어미, 출처 방식은 후속이 재질문하지 않는다.
- 슬롯 2 핵심 독자는 feedback 페르소나 기준축이 된다.
- 슬롯 4는 기획 단계 개요를 **요약하지 말고** 옮긴다.
- 슬롯 5, 6은 기획 시 비어 있어도 된다.

## B. 강의 프로필 (`pipeline: lecture`)

같은 파일에 슬롯 의미를 매핑합니다.

| 슬롯 | 강의에서의 의미 |
|------|-----------------|
| 0 | 강의명, 시간, 대상, 어미(슬라이드 vs 스크립트) |
| 1 | 학습 목표, 하지 않을 것 |
| 2 | 학습자 프로필 |
| 3 | 꼭지(세션) 목차 |
| 4 | 꼭지별 메시지, 시간 |
| 5 | 강사 경험, 데모 요청 |
| 6 | 사례, 수치, 시각 소재 리서치 요청 |

상세 12슬롯 리서치 카드는 `research-card-schema.md`의 lecture 프로필을 씁니다.

## C. 사업계획 프로필 (`pipeline: bizplan`)

| 슬롯 | 의미 |
|------|------|
| 0 | 사업명, 한 줄 정의, 업종, 작성 목적(투자/내부) |
| 1 | 문제, 해결 한 문장, 쓰지 않을 시장 |
| 2 | 고객 프로필 |
| 3 | 본문 목차(문제, 해결, 시장, 모델, 성장, 팀 …) |
| 4 | 섹션별 개요 |
| 5 | 자사 경험, 실적 요청 (U 카드) |
| 6 | 시장, 경쟁, 자금 리서치 요청 |

집필 입력 JSON/카드는 `research-card-schema.md` biz 프로필.

## D. 소설 프로필 (`pipeline: novel`)

| 슬롯 | 의미 |
|------|------|
| 0 | 가제, 장르, 분량, 시점 |
| 1 | 로그라인, 테마 |
| 2 | 독자, 비교작 |
| 3 | 구조(막/시퀀스) |
| 4 | 인물, 관계 요약 |
| 5 | 파일럿 씬 요청 |
| 6 | 세계관, 조사 요청 |

보이스 확정 후 `novel-voice` 산출이 서술 어미, 금칙을 덮어씁니다.
