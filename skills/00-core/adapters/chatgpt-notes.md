# ChatGPT 적재 메모

Claude Skills(`.skill`)와 달리 Custom GPT / Project는 슬래시 호출, 로컬 FS 체인이 없습니다. 
코어와 체인 스킬을 나눌 때의 주의만 정리합니다.

---

## 1. 권장 적재

| 위치 | 넣을 것 |
|------|---------|
| Instructions | 스킬 목적, 단계 요약, 출력 포맷, 트리거 한 줄 + “00-core 우선” |
| Knowledge / Project 파일 | `00-core` 전체, 해당 체인 스키마, 예시 |
| 대화 | 인계 블록 붙여넣기 또는 Project 파일 갱신 |

한 GPT에 글쓰기 전 채널을 동시에 넣지 않습니다. 파이프라인 단위로 나눕니다.

---

## 2. 핸드오프

- 파일이 자동으로 다음 스킬에 전달되지 않는다.
- 사용자에게 `00-handoff.md` 내용을 복사, 업로드하게 안내한다.
- Project 파일을 쓰는 경우: 같은 스레드에서 “handoff 파일 기준으로 계속”이라고 명시한다.

---

## 3. 위키, 볼트

- 로컬 볼트 전제를 “Project 파일 = 위키 루트”로 완화한다.
- `[[위키링크]]`는 텍스트로 유지하되, 앱 밖에서는 경로 문자열로도 통하게 쓴다.

---

## 4. 런타임

- docx/pptx 코드 실행이 없으면 MD 스펙만 산출한다.
- 사용자 환경에 다운로드, 변환이 있으면 `runtime-files.md` 원칙만 안내한다.

---

## 5. 코어 동기화

Knowledge에 넣은 `00-core` 사본이 스토어와 어긋나지 않게, 재구성 후에는 **코어를 다시 업로드**한다. 
스킬 Instructions에 코어 내용을 장문으로 복제하지 않는다.
