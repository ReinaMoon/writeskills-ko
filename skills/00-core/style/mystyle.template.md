# mystyle 템플릿 (사용자 문체 슬롯)

이 파일을 복사해 `mystyle.md`로 저장한 뒤 슬롯을 채웁니다. 
특정인 문장 복제 예시가 아니라 **운영용 규약**입니다. 비어 있는 슬롯은 기본값(합니다체, IT 실무 톤)을 씁니다.

---

## 0. 메타

| 항목 | 값 |
|------|-----|
| 스타일 이름 | {예: 팀 기본 / 개인 칼럼} |
| 기본 종결어미 | `합니다` / `다` / 기타 `{ }` |
| 기본 시점 | 1인칭 / 3인칭 / 혼용 금지 |
| 적용 범위 | 전 스킬 / 글쓰기만 / 책만 |
| 최종 갱신 | YYYY-MM-DD |

---

## 1. 한 문장 정의

이 문체로 쓰는 글은 무엇인가 (1문장):

> {예: 관찰 > 문제 재정의 > 판단 기준 이동 중심의 설명문}

---

## 2. 어조, 위치

| 슬롯 | 채우기 |
|------|--------|
| 독자와의 거리 | {가르치기 / 동료 / 관찰자 / 안내자} |
| 설득 방식 | {납득 / 논증 / 공감 / 지시} |
| 피하고 싶은 어조 | {예: 동기부여형 CTA, 감탄형} |

짧은 예시 (허용 1개 / 금지 1개):

- 허용: `{ }`
- 금지: `{ }`

---

## 3. 서술 습관

원하는 습관만 체크, 채웁니다.

- [ ] 실행, 장면을 개념보다 먼저 둔다
- [ ] 간접 인용("~라고 한다")을 선호한다
- [ ] 1인칭 경험을 우선한다
- [ ] 데이터, 출처를 문장 안에 붙인다
- [ ] 기타: `{ }`

진입 패턴 (첫 문장 선호):

> {문제 상황 / 관찰 / 정의 / 질문 / 수치}

논리 골격 (기본 순서):

> {관찰 > 오해/문제 > 기준 재정의 > 적용}

---

## 4. 리듬, 문단

| 항목 | 기본값 | 내 값 |
|------|--------|-------|
| 단문 기준 | ≤15단어 | |
| 중문 기준 | 18~25단어 | |
| 문단 문장 수 | 3~5 | |
| 문단 패턴 | 앞은 가볍게, 뒤로 판단 밀도↑ | |

규칙:

1. 같은 길이 문장이 3개 이상 연속되면 길이를 교차한다.
2. 문단 첫 문장은 단문을 기본으로 한다 (사용자가 달리 정하면 그에 따름).
3. 판단, 결론 문장은 접속사 남발 없이 독립적으로 둔다.
