# 스킬 문서 문체 (토큰 절약)

스킬 `SKILL.md` / 짧은 references에 적용. 사용자에게 **쓰는 산출물** 문체와 별개다. 산출물은 `mystyle` / `tone-matrix`를 따른다.

**README는 적용하지 않는다.** 루트/카테고리 README는 목적, 선택 기준, 체인, 코어, 비범위, 예시 링크를 자세히 둔다.

## 규칙

1. 문장은 짧게. 가능하면 명사형, 명령형.
2. "합니다/합니다체 설명"으로 스킬 문서를 쓰지 않는다.
3. 같은 말을 표 + 본문에 중복하지 않는다.
4. 코어 링크는 필수 2~3개만 (`core-ref-diet`).
5. 볼드, 슬로건, 가운뎃점, 긴 대시, 세미콜론 금지.
6. 예시는 링크로만. 본문에 긴 샘플을 붙이지 않는다.
7. 섹션 고정: 한 줄 목적 → 코어 → 입력 → 절차 → 출력 → 규칙 → 완성 → 형제

## 변환 예

- 전: 회의가 끝난 뒤 실행 가능한 기록을 남긴다.
- 후: 회의 후 실행 기록. 결정/액션/미결 분리.
