# mystyle 온보딩 게이트

글쓰기, 책, 에세이, 소설 체인에 진입할 때 **한 번** 적용합니다. IT 실무(`doc-*`)는 이 게이트를 건너뜁니다.

## 언제

- 세션/프로젝트에서 해당 체인을 **처음** 쓸 때
- 사용자가 문체, 어미, 시점을 바꾸자고 할 때

## 절차 (최대 1분)

1. 프로젝트에 `mystyle.md`가 있는지 확인한다.
2. **있으면** 읽고 그대로 적용한다. 재질문하지 않는다.
3. **없으면** 아래 중 하나만 한다 (둘 다 하지 않음).
 - A. 사용자에게 슬롯 4개만 묻는다: 종결어미 / 시점 / 어조(한 줄) / 피하고 싶은 말투
 - B. 사용자가 “기본으로”라고 하면 `tone-matrix.md` 해당 장르 + 합니다체로 진행하고, 대화 끝에 `mystyle.md` 초안을 제안한다
4. 답변을 `mystyle.md`로 저장(또는 대화에 고정)한 뒤 본 스킬 Step으로 간다.

## 묻지 말 것

- 장르마다 문체를 다시 묻지 않는다 (이미 게이트를 통과했으면).
- 특정 유명 작가 문장 복제를 기본값으로 제안하지 않는다.
- IT 문서에서 액션, 오너, 기한 필드를 문체 때문에 지우지 않는다.
