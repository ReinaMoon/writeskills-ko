# 한국어 산문 규칙

한국어 산출물의 공통 문법, 호응 규칙입니다. 장르 톤은 `tone-matrix.md`를 따릅니다.

---

## 1. 종결어미

| 규칙 | 내용 |
|------|------|
| 통일 | 한 문서 안에서 `~합니다` / `~다` / 명사형 개조식을 **혼용하지 않는다** |
| 기본값 | 미지정 시 **합니다체** |
| 인계 우선 | 기획 인계, 보이스 파일에 어미가 있으면 그것을 따른다 |
| 인용, 대사 | 인용문, 소설 대사는 문서 어미와 달라도 된다. 인용 밖 서술만 통일 |
| IT 개조식 | 런북, 체크리스트는 명사형(`~함`, `~할 것`) 허용. 같은 섹션 안에서만 통일 |

합니다체 간결화:

- 축약형(`됐습니다`)보다 풀어 쓴 형태(`되었습니다`)를 기본으로 한다 (사용자가 구어를 원하면 예외).
- 복합 종결(`바뀌어 있었습니다`)은 단순 종결(`되었습니다` / `입니다`)로 줄인다.
- 의미 없는 수식, 군더더기 종결을 붙이지 않는다.

---

## 2. 호응, 조사

- 주어와 서술어 호응을 맞춘다 (복수, 존칭, 시제).
- 긴 관형절이 3단 이상 겹치면 문장을 나눈다.
- `의` 남발 대신 조사, 동사로 관계를 드러낸다.
- `하다` 명사화 남발(`~화`, `~성`)을 줄이고 구체 동사를 쓴다.
- 피동, 이중 피동(`되어지다`)을 피하고 능동 또는 단일한 피동을 쓴다.

---

## 3. 문장 호흡

| 항목 | 권장 |
|------|------|
| 기본 길이 | 18~25단어 내외 (장르에 따라 `tone-matrix`가 조정) |
| 과장문 | 25~30단어 초과 시 분리 검토 |
| 단문 | 문단 첫 문장, 전환 문장에 활용 |
| 병렬 | `~하고, ~하며, ~한다` 3단 이상 병렬은 목록 또는 문장 분리 |

---

## 4. 표기

- 숫자: 단위를 붙인다 (`30%`, `3단계`, `10분`).
- 외래어, 제품명: 문서 내 표기를 하나로 고정한다 (첫 등장 시 필요하면 원어).
- 따옴표: 한국어 문서에서는 `""` 또는 `『』` 중 하나를 문서 단위로 통일.
- 날짜: `YYYY-MM-DD` (타임존이 필요하면 KST 명시).

### 쓰지 않는 기호, 습관

- 가운뎃점(`, `)을 쓰지 않는다. 나열은 쉼표(`,`)나 슬래시(`/`)를 쓴다.
- 긴 대시(`: `, `–`)를 쓰지 않는다. 설명은 마침표나 콜론(`:`)으로 잇는다.
- 세미콜론(`;`)을 쓰지 않는다. 문장을 나누거나 쉼표를 쓴다.
- 화살표(`→`)로 문장을 꾸미지 않는다. 순서 안내는 `>` 또는 말로 적는다.
- “혁신적인”, “한층 더”, “라고 할 수 있습니다” 같은 AI 상투어는 `writing-principles.md`를 따른다.

---

## 5. 경어, 독자 호칭

- 독자를 `여러분`으로 반복 호명하지 않는다.
- 명령형은 IT 런북, 실습 지시에서만. 칼럼, 에세이에서는 기준 제시형.
- 팀 문서: 이름, 역할은 이슈트래커/위키에 있는 표기를 그대로 쓴다.

---

## 6. 자가 점검 (제출 전)

- [ ] 종결어미가 문서 전체에서 하나로 통일되었는가
- [ ] 주술 호응, 시제가 맞는가
- [ ] 한 문장에 정보가 과다하게 겹치지 않는가
- [ ] 맞춤법, 띄어쓰기 기본 오류가 없는가
