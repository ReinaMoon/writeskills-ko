# 한국어 AI 말투 패턴

LLM이 쓴 한국어에서 자주 보이는 습관 목록입니다.  
`edit-de-ai`가 진단 기준으로 쓰고, 다른 스킬은 G3 문장 게이트에서 참고합니다.

판정은 "하나라도 있으면 실패"가 아닙니다. **밀도**를 봅니다. 한 문단에 2개 이상 겹치면 고칩니다.

---

## 1. 어휘 패턴

| ID | 패턴 | 예 | 고치는 방향 |
|----|------|----|-------------|
| V1 | 과장 형용사 | 혁신적인, 획기적인, 놀라운, 강력한 | 구체 수치나 사실로 교체, 없으면 삭제 |
| V2 | 추상 명사 나열 | 효율성, 생산성, 가능성, 시너지 | 무엇이 몇 % 나아졌는지로 교체 |
| V3 | 상투 동사 | 살펴보겠습니다, 알아보겠습니다, 탐구해 봅시다 | 바로 본론 |
| V4 | 의미 없는 강조 | 매우, 정말, 진정한, 핵심적인 | 삭제 후 문장이 약해지면 근거 추가 |
| V5 | 번역형 접속 | 이를 통해, 이러한 측면에서, 그럼에도 불구하고 | 그래서, 그런데, 하지만 |
| V6 | 마법 단어 | 여정, 풍경, 생태계(비유), 한 걸음 더 | 실제 대상 이름 |

## 2. 문장 패턴

| ID | 패턴 | 예 | 고치는 방향 |
|----|------|----|-------------|
| S1 | 3개 나열 강박 | A, B, 그리고 C까지 | 진짜 필요한 1~2개 |
| S2 | "단순히 A가 아니라 B" | 단순한 도구가 아니라 파트너입니다 | B만 사실로 서술 |
| S3 | 수사 의문문 도입 | ~해 본 적 있으신가요? | 상황 묘사로 시작 |
| S4 | 모든 문장 같은 길이 | 40~50자 반복 | 짧은 문장 섞기 |
| S5 | 피동, 명사화 과다 | ~가 이루어지고 있습니다 | 주어 + 능동 동사 |
| S6 | 양다리 결론 | 장단점이 있으므로 상황에 맞게 | 어떤 상황에 무엇인지 명시 |
| S7 | 긴 대시, 세미콜론 | 문장 — 덧붙임; 이어짐 | 문장 분리, 쉼표 |

## 3. 구조 패턴

| ID | 패턴 | 고치는 방향 |
|----|------|-------------|
| T1 | 서론에서 주제 반복 정의 | 첫 문단에 결론이나 사건 |
| T2 | 모든 절이 같은 골격 (정의, 장점, 단점) | 독자 질문 순서로 재배치 |
| T3 | 과한 소제목, 굵은 글씨 | 짧은 글은 소제목 0~2개 |
| T4 | 이모지 머리표 | 삭제 |
| T5 | 마무리 요약 + 격려 | "도움이 되셨길 바랍니다" 삭제, 다음 행동 1개 |
| T6 | 근거 없는 일반론 | 경험, 수치, 출처 중 하나 붙이거나 삭제 |

## 4. 한국어 특유

| ID | 패턴 | 고치는 방향 |
|----|------|-------------|
| K1 | ~하는 것이 중요합니다 반복 | 왜 중요한지 결과로 |
| K2 | ~할 수 있습니다 남발 | 확실하면 단정, 아니면 조건 |
| K3 | 존댓말 수위 흔들림 | 합니다체/해요체/한다체 하나 |
| K4 | 번역투 소유격 "~의 ~의" | 조사 줄이기 |
| K5 | "~에 대해" 과다 | 목적어로 바로 |

---

## 판정 표 형식

```markdown
| ID | 위치 | 원문 | 수정 |
|----|------|------|------|
```

밀도 점수: 문단당 패턴 수 평균. 0.5 이하 통과, 1.0 이상 재작성 권장.
