# 표기 방식 요약

상세 예시는 필요 최소만. 확정 후 Step 4에서 동일 포맷을 유지한다.

## 1. 국내 실용서

- 본문: (저자, 연도) / (저자, 저자, 연도) / (저자 외, 연도) / 기관명 가능
- 목록: 가나다>알파벳. `저자 (연도). 『제목』. 출판지: 출판사.`
- 웹: 기관 (연도). 제목. URL (접속일: YYYY.MM.DD)

## 2. 국내 학술 (KCI)

- 본문: 각주(위첨자). 첫 인용 전체, 직전 동일 "위의 책", 이전 "앞의 책"
- 목록: 단행본, 논문, 학위, 보고서 관행 형식

## 3. APA 7th

- 본문: (Author, Year) / (Author & Author, Year) / (Author et al., Year)
- References: 알파벳, hanging indent. DOI 권장

## 4. Chicago (Notes-Bibliography)

- 본문: 각주/미주 전체 > 이후 약식 / Ibid.
- Bibliography: Last name 기준. 한국어는 저자명 그대로 + 『제목』

## 5. 간략형

- 본문 표기 최소(직접 인용만). 장 말미 "참고 자료" 한 줄 형식: `저자, 『제목』, 출판사, 연도`

## 변환

각주↔괄호, 장 말미↔책 말미, 방식 전체 전환 시 Step 1 재확정 후 Step 4만 재실행(출처 정보 유지).
