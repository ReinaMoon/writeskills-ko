# 챕터 집필 보조 규칙

## 오프닝 유형 (도입 슬롯)

챕터 기능에 맞춰 후보 3개를 만든 뒤 1개를 고른다.

| 기능 | 적합한 오프닝 |
|------|----------------|
| 개념 도입 | 장면, 사실, 짧은 질문 |
| 방법론 | 잘못된 선택 장면 > 기준 예고 |
| 근거 | 수치, 사례 한 컷 > 해석 약속 |
| 관점 전환 | 통념 한 줄 > 재정의 |

금지: "이번 장에서는 ~를 다룬다", 기능 소개형 첫 문장.

평가: 구체성, 주제 연결(다리), 메타 선언 없음, 관점 반영, 3~6문장.

## 실무 정리 블록

- 적용 체크리스트 (실행 가능 항목)
- 자주 하는 실수 (원인 1줄)
- 구조 예시 (프롬프트, 표, 절차 등 1개)

형식, 깊이가 챕터마다 크게 흔들리지 않게 맞춘다.

## 경험 주입

- 본문에 녹인다. 사이드바, 콜아웃 분리 금지.
- 유형(직접/관찰/실패/전환)에 맞는 서술 톤.
- 판단 기준으로 귀결. 동기부여 문장으로 끝내지 않음.
- 동일 사례 복수 챕터 반복 금지. 소제목 분량 +30% 초과 시 확인.
