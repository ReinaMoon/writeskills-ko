# editor 모드 상세

## 유형 판정

| 신호 | 모드 |
|------|------|
| 도구, 버전, 프레임워크가 전제 | 기술, 스킬북 |
| 1인칭 현장이 본문 절반+ | 현장 노트 |
| 그 외 방법, 관점 중심 | 실용서, 자기계발 |
| 두 신호 강함 | 주 모드 5축 + 부 모드 2축 (상한 7) |

## 1. 관찰 (판정 금지)

한 줄 콘셉트 병치, 기획서 매핑(정합도 열은 평가 단계에서), 관점 선언 등장 위치, 차별점 위치, 포지션 어긋남 위치.

## 2. 구조 점검

- 목차: 순서, 분량, 중복, 누적성, 시작/끝 (간이, 정밀)
- 챕터: 주장 한 줄, 사례/인용 수, 분량, 연결, 모드별 축 (정밀만)
- 챕터당 ≤600자, 구조 점검 분량은 원고의 25% 이하

## 3. 평가

한 줄 평, 강점/약점 Top 3, 완성도, 다음 단계(수정/베타/투고 검토), High/Mid/Low, 편집자 코멘트 3~5문장.
간이: High와 완성도, 다음 단계 중심. 평가 본문 ≤2,500자.

High 예: 콘셉트 불일치, 약속 위반, 관점 미구현, 핵심 챕터 사례 0, 목차 붕괴, (기술) 재현 환경 미명시, (현장) 약속 비중 미달.
