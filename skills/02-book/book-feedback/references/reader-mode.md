# reader 모드 상세

## 페르소나

- 간이 3명 / 정밀 4~5명. 지식, 동기, 읽기 강도 중 2축 이상 차이.
- 인계 핵심 독자 = 페르소나 1, 확장 독자 = 스펙트럼 바깥.
- 카드: 이름, 나이, 직업, 사전 지식(구체), 읽기 동기, 읽기 상황, 기대, 참을 수 없는 것, 핵심 질문 1~2.
- 챕터 6+ 또는 간이: 챕터당 관련 페르소나 2명만.

## 관찰 출력 (실용서)

챕터 × 페르소나마다: 재현 / 전제 / 실습 연결 / 참조 충분 / 경험 주입. 
각 줄: `[라벨][위치]: 관찰 사실`

## 관찰 출력 (서사)

이해 막힘 / 속도 저하 / 의문 / 이탈 가능 위치. 동일 라벨 규칙.

## 평가

- 전원 막힘 > 구조 High
- 갈림 > 타깃, 분기 서술
- 반복 누락 > 본문 보강, FAQ
- `[시뮬추정]`만 있으면 우선순위 한 단계 하향 검토

## 후속 매핑

구조, 문장 > editing, 전제, 근거 > research, 경험 > writing, 출처 > citation, 콘셉트 붕괴 > planning/editor
