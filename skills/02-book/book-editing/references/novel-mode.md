# book-editing 소설 모드

`novel-writing` 이후 공유 퇴고. 실용서 Pass의 실무 정리, 기준>근거, 경험 논증 항목을 아래로 교체한다. 
코어: `../../../00-core/output/quality-gates.md` 소설 모드 절과 동기화.

## 전제

- `style-guide.md`(novel-voice) 또는 설계 키트의 시점, 어미, 금지 표현을 정본으로 둔다.
- 원고를 L2/L3로 다듬되, 플롯, 인물을 임의로 바꾸지 않는다. 구조 제안은 리포트에 분리.
- Light는 표현만, Standard는 씬 단위 재배치 허용, Deep은 장면 재작성 허용(분량 한도 동일).

## Pass 1: 구조 (소설)

| # | 항목 |
|---|------|
| 1 | 씬 목적: 각 장면이 갈등, 정보, 관계를 전진시키는가 |
| 2 | 페이싱: 늘어지거나 급전개로 감정 곡선이 깨지는가 |
| 3 | 시점 일관성: 제한/전지/1인칭 규칙 위반 없음 |
| 4 | 정보 공개 타이밍: 설명문으로 설정을 덤프하지 않는가 |
| 5 | 인과: 사건 연결이 우연 남발인가 |
| 6 | 인물 아크: 욕망, 결핍이 행동으로 드러나는가 |
| 7 | 장면 전환: 장소, 시간 점프에 독자 이정표가 있는가 |
| 8 | 클라이맥스, 결말: 전제, 테마와 일치하는가 |
| 9 | 중복 장면, 반복 감정 비트 |
| 10 | 보이스 규약 대비 톤 드리프트 |

## Pass 2: 문장 (소설)

| # | 항목 |
|---|------|
| 1 | Show, don't tell: 감정 형용사 직접 서술 > 행동, 감각 |
| 2 | 문장 리듬: 긴장 장면일수록 단문 |
| 3 | 감각 채널: 장면당 규약 기준(기본 2+) |
| 4 | 대화 개성: 인물 말투가 설계서/규약과 일치 |
| 5 | 설명적 대사, 작가 개입 제거 |
| 6 | 금지 전환 부사("갑자기", "문득") 남용 |
| 7 | 어미, 시제 통일 |
| 8 | 보이스 7축 목표값 이탈 |
| 9 | AI 흔적, 과장 수사 |

## 씬 단위 미니 체크 (Pass 1 보조)

장면마다 한 줄로 답한다.

1. 이 장면의 목적(갈등/정보/관계)은?
2. 들어가기 전과 나온 뒤 무엇이 바뀌었나?
3. 설명 덤프 문단이 있는가? 있으면 행동, 대사로 옮길 수 있는가?
4. 시점 캐릭터 밖으로 샌 정보가 있는가?
5. 보이스 금지 목록 위반 문장이 있는가?

채워진 예: `../examples/scene-checklist-filled.md`

## Pass 3

실용서와 동일. 고유명사, 세계관 용어 일관성 강화. 인용 탐지는 보통 불필요(필요 시 citation).

## 완성 조건 (소설)

- [ ] 보이스 규약 위반 없음 (또는 리포트에 위치)
- [ ] 시점 일관성
- [ ] 설명문 과다, 스포일러성 개입 정리
- [ ] 재검증 통과
