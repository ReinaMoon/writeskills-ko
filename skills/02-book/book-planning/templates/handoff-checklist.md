# 인계 작성 체크리스트

정본 스키마: `../../../00-core/handoff/handoff-schema.md` (book 프로필).

파일: `00-handoff.md`

## 슬롯

| 슬롯 | 내용 | 기획에서 가져올 것 | 읽는 스킬 |
|------|------|-------------------|----------|
| 0 | 가제, 장르, 분량, 종결어미, 출처 표기, 용도 | 기본 설정 + 확인 | 전 스킬 |
| 1 | 콘셉트, 차별점, 변화, 쓰지 않을 것 | 콘셉트 | writing, feedback |
| 2 | 독자 프로필, 반복 질문 | 독자 | writing, feedback |
| 3 | 목차 | 목차 | research, writing |
| 4 | 챕터별 개요 | 챕터 개요 | research, writing |
| 5 | 경험 소재 요청 | 챕터 개요 / 경험 메모 | writing |
| 6 | 리서치 요청 | 챕터 개요 / 리서치 메모 | research |

## 규칙

- 슬롯 헤더 0~6 유지. 내용이 없으면 `[미정]`.
- 슬롯 0 어미, 출처는 후속이 재질문하지 않음 (`[미정]`일 때만).
- 슬롯 4는 기획 개요를 **요약하지 말고** 옮긴다.
- 갱신 전 기존 파일이 있으면 `00-handoff_YYYYMMDD-HHMM.md`로 백업.
