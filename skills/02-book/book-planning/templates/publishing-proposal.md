# 출판 기획서 템플릿

용도: 출판사 제안 / 자가출판 / 내부 검토. 톤만 조정하고 절 순서는 유지한다.

```markdown
# {가제} 출판 기획서

## 1. 제목, 부제
- 안 1 / 안 2 / 안 3

## 2. 작성자 소개
이 주제를 쓸 자격, 경험 (약력 나열이 아니라 "왜 이 사람이 쓰는가")

## 3. 기획 의도
왜 지금 이 책이 필요한가 (300~500자). 콘셉트 한 문장 포함.

## 4. 독자 대상
핵심 / 확장 / 현재 상태 / 기대 / 읽은 뒤 변화

## 5. 시장, 차별점
유사서 3~5, 각 한계, 이 책의 차별 한 줄, 타이밍

## 6. 목차
파트 → 챕터 (번호 2자리)

## 7. 챕터별 개요 요약
챕터마다 핵심 논점 + 소제목만

## 8. 예상 사양
총 분량, 집필 기간, 판형, 특이사항

## 9. 마케팅 포인트
(출판사 제안용만) 채널, 기존 독자층, 홍보 자산
```

자가출판이면 §9를 일정, 작업 계획으로 바꾸고, 내부 검토면 역할 분담, 결정 항목을 넣는다.
