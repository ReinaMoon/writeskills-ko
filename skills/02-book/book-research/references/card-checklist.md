# 참조 카드 자가 점검

스키마 정본: `../../../00-core/handoff/research-card-schema.md`

## 공통

- [ ] 과장형 형용사, 모호 부사, 근거 없는 추측 없음
- [ ] ② 수치에 기관, 연도, URL(가능 시), 등급, 조사일
- [ ] 원문 미확인 항목에 `[스니펫 기반: 원문 미확인]`
- [ ] 슬롯 순서 유지, 빈 슬롯은 `[조사 미흡: …]`
- [ ] 챕터 번호 2자리, 인계 목차와 일치

## A 모드

- [ ] ③ 사례에 "집필 활용" 1문장
- [ ] 분량 1,000~1,200자

## B 모드

- [ ] ③에 "원고 인용 위치" + "검증 결과"(일치/불일치)
- [ ] ⑥ 교차 인용 포함
- [ ] 분량 1,500~2,200자

미달 시 해당 항목만 수정 후 재점검(최대 2회). 이후에도 미달이면 위치, 사유를 보고한다.
