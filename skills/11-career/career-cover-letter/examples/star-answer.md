# 예시: 문제 해결 문항 (500자)

문항: 예상하지 못한 문제를 해결한 경험을 쓰세요. (500자)

## 흔한 초안 (AI 말투 밀도 높음)

> 저는 항상 문제 해결에 대한 열정을 가지고 있습니다. 프로젝트 진행 중 예상치 못한 문제가 발생했지만, 포기하지 않고 팀원들과 소통하며 끈기 있게 해결해 나갔습니다. 이를 통해 협업의 중요성과 문제 해결 능력을 기를 수 있었습니다.

문제: 상황, 행동, 결과가 없음. 열정/소통/끈기 단어만 있음.

## STAR 수정본 (482자)

> 배포 직후 주문 API 응답이 3초 넘게 느려진 적이 있습니다. 롤백해도 증상이 남아 코드 문제가 아니라는 것만 확실했습니다.
>
> 저는 배포 시점 전후의 DB 지표를 비교했고, 같은 날 다른 팀이 추가한 배치 작업이 주문 테이블 전체를 읽고 있다는 것을 찾았습니다. 해당 팀과 통화해 배치를 새벽 시간대로 옮기고, 임시로 읽기 전용 복제본을 보도록 바꿨습니다. 이 과정을 30분 안에 마쳤습니다.
>
> 이후 같은 일이 반복되지 않게 배치 작업 등록 시 대상 테이블과 실행 시간을 적는 체크리스트를 만들었고, 지금은 플랫폼팀 표준 절차가 됐습니다. 이 경험으로 장애를 볼 때 내 코드보다 먼저 "그 시점에 무엇이 바뀌었나"를 확인하는 습관이 생겼습니다.

| 구간 | 비율 |
|------|------|
| 상황 + 과제 | 약 25% |
| 행동 | 약 50% |
| 결과 + 배운 점 | 약 25% |
