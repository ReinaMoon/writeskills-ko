# career-interview

답변 원고 암기용이 아니라 **카드**(핵심 3줄 + 근거). 없는 경험 창작 금지.

## 코어 참조

필수: `../../00-core/principles/korean-prose-rules.md`  
레퍼런스: `references/question-bank.md`  
예시: `examples/answer-card.md`

## 입력

경력기술서/자소서(필수), 공고(권장), 면접 유형(인성|기술|컬처|임원), 모의 면접 여부.

## 모드

| 모드 | 신호 | 산출 |
|------|------|------|
| 준비 | 기본값 | 예상 질문 15~25개 + 답변 카드 |
| 모의 | 모의 면접, 질문해 줘 | 1문씩 질문, 답 받고 피드백 + 꼬리 질문 |
| 기술 설명 | 개념 설명 연습 | 30초/2분 두 버전 설명 + 흔한 오답 |

## 워크플로

1. 서류에서 질문 뽑기: 성과 문장마다 "어떻게", "왜", "다시 하면".
2. 공고 키워드 기반 질문, `question-bank.md` 공통 질문.
3. 질문별 답변 카드: 결론 1줄, 근거 2줄, 예상 꼬리 질문 2개.
4. 약점 질문(공백기, 이직 사유, 연봉)은 사실 + 방향으로.
5. 모의 모드: 답변 평가 (구체성, 길이, 결론 위치) 후 다음 질문.

## 출력

```markdown
## 예상 질문
| # | 질문 | 출처 | 난도 |
## 답변 카드
### Q3 캐시 도입 시 일관성은 어떻게 처리했나요?
- 결론:
- 근거:
- 꼬리: 
## 역질문 후보 3개
```

## 규칙

- 답변 1개 1분 안팎 (말하기 300자 내외).
- 모르는 기술 질문은 "모른다 + 아는 범위 + 찾는 방법" 구조 연습.
- 이전 회사 험담 표현 감지 시 수정 제안.

## 완성

서류 기반 질문 포함, 카드마다 꼬리 질문, 역질문
