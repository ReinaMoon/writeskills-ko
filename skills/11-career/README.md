# 11-career: 이력서, 자기소개서, 면접

이직이나 취업을 준비하는 사람을 위한 스킬 3개입니다. 기본 예시는 IT 직군이지만 구조는 다른 직군에도 그대로 씁니다.

이 카테고리의 원칙은 하나입니다. **없는 경험과 수치를 만들지 않는다.**  
대신 이미 한 일을 "행동 + 결과 + 수치" 문장으로 바꾸고, 비어 있는 수치는 `[수치?]`로 표시해 사용자에게 묻습니다.  
AI가 그럴듯하게 지어낸 성과는 면접 꼬리 질문 한 번에 무너지기 때문입니다.

## 스킬 목록

| 스킬 | 목적 | 언제 쓰나 | 예시 |
|------|------|-----------|------|
| [career-resume](./career-resume/SKILL.md) | 이력서, 경력기술서 | 업무 메모를 성과 문장으로 | `examples/task-to-achievement.md` |
| [career-cover-letter](./career-cover-letter/SKILL.md) | 자기소개서, 지원동기 | 문항별 STAR + 글자수 | `examples/star-answer.md` |
| [career-interview](./career-interview/SKILL.md) | 예상 질문, 답변 카드, 모의 면접 | 서류 통과 후 | `examples/answer-card.md` |

## 체인

```
doc-weekly / doc-project-book (평소 기록)
  → career-resume → career-cover-letter → career-interview
  → edit-de-ai → edit-proofread (제출 전)
```

평소에 `doc-weekly`, `doc-project-book`으로 남긴 기록이 있으면 이력서 원자료로 그대로 넣으면 됩니다.  
IT 실무 스킬과 이어지는 지점이라, 이 레포를 업무 기록부터 이직까지 한 흐름으로 쓸 수 있습니다.

## 이렇게 쓰세요

| 하고 싶은 일 | 프롬프트 예 |
|--------------|-------------|
| 메모를 경력기술서로 | "작년 주간보고 붙여 넣을게. 경력기술서 프로젝트 항목으로 바꿔 줘" |
| 공고 맞춤 | "이 공고랑 내 경력기술서 키워드 매칭해 줘" |
| 자소서 | "문항 3개, 각 700자. 경험 배정부터 해 줘" |
| 모의 면접 | "내 경력기술서로 기술 면접 모의로 한 문제씩 질문해 줘" |

## 이 카테고리 범위 밖

- 특정 채용 플랫폼 양식 자동 입력
- 합격 보장, 연봉 협상 대행
- 경력 부풀리기, 허위 기재
