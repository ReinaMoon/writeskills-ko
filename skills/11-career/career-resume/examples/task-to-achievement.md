# 예시: 주간보고 메모 → 경력기술서

## 입력 (사용자 메모)

> 작년에 주문 서비스 쪽 일 함. 레디스 캐시 붙였고 쿼리 튜닝도 했음. 장애 대응 많이 했고 런북 정리함. 주니어 2명 코드리뷰.

## 출력

#### 주문 서비스 성능 개선 (2025.03 ~ 2025.09, 역할: 단독 설계, 구현)
- 주문 목록 조회에 Redis 캐시 계층을 도입해 p95 응답시간을 [수치?]에서 [수치?]로 줄임
- 느린 쿼리 [수치?]건의 실행 계획을 분석해 인덱스를 재설계, DB CPU 사용률 [수치?]% 감소
- 장애 대응 절차를 런북 [수치?]개로 정리해 평균 복구 시간을 [수치?]분 단축
- 주니어 개발자 2명의 코드리뷰를 맡아 [결과?: 예) 리뷰 대기 시간, 재작업 비율]
- 기술: Java, Spring, Redis, MySQL

## 채워야 할 수치

1. 캐시 도입 전후 p95 (모니터링 대시보드 캡처가 있으면 가장 좋음)
2. 튜닝한 쿼리 수, DB CPU 전후
3. 런북 개수, 복구 시간 전후 (모르면 "온콜 신규 인원도 단독 대응 가능" 같은 정성 결과)
4. 코드리뷰로 생긴 변화 (없으면 이 줄은 빼는 것을 권장)
