# 경력기술서 템플릿

```markdown
# {이름}
{직무 한 줄: 예) 결제 도메인 백엔드 개발자, 7년}
{연락처} | {GitHub/포트폴리오}

## 요약
- {대표 성과 1, 수치 포함}
- {대표 성과 2}
- {주력 기술 4~6개}

## 경력

### {회사} | {직책} | {YYYY.MM ~ YYYY.MM}
{팀/서비스 한 줄 소개, 규모}

#### {프로젝트명} ({YYYY.MM ~ YYYY.MM}, 역할: 리드|기여|단독)
- {성과 문장}
- {성과 문장}
- 기술: {스택}

## 기술
| 분류 | 기술 | 수준 메모 |

## 그 외
- 발표, 오픈소스, 글, 자격 (직무 관련만)
```

## 분량 기준

| 연차 | 권장 |
|------|------|
| 0~3년 | 1~2쪽 |
| 4~10년 | 2~3쪽, 최근 5년 상세 |
| 10년+ | 3~4쪽, 오래된 경력은 한 줄 요약 |

## 영문 resume

요청 시 같은 구조로, 성과 문장은 과거형 동사로 시작 (Reduced, Migrated, Led).  
한국어 원문을 직역하지 말고 공식으로 다시 쓴다.
