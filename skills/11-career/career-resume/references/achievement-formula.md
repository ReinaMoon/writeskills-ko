# 성과 문장 공식

## 기본형

**[무엇을] [어떻게] 해서 [결과]를 [수치]만큼 바꿨다.**

| 요소 | 질문 | 예 |
|------|------|----|
| 대상 | 무엇을 | 결제 API 조회 쿼리 |
| 행동 | 어떻게 (동사) | 인덱스 재설계, 캐시 계층 도입 |
| 결과 | 무엇이 달라졌나 | p95 응답시간 |
| 수치 | 얼마나 | 820ms → 140ms |
| 범위 | 내 역할 | 단독 설계, 구현 |

## 수치가 없을 때 묻는 질문

1. 전후로 비교할 수 있는 숫자가 있나요? (시간, 비용, 건수, 에러율, 사용자 수)
2. 없으면 규모로: 몇 명이 쓰는, 몇 건을 처리하는, 몇 개 팀이 쓰는
3. 그것도 없으면 빈도로: 주 몇 회 하던 수작업을 없앴다
4. 그것도 없으면 최초, 유일: 팀 최초로 도입, 사내 표준으로 채택

## 약한 문장 → 강한 문장

| 약함 | 강함 |
|------|------|
| 배포 자동화 담당 | 수동 배포 절차를 CI 파이프라인으로 옮겨 배포 시간을 2시간에서 15분으로 줄임 (단독) |
| 모니터링 시스템 구축 참여 | 알림 규칙 40개를 정리해 오탐을 주 30건에서 5건으로 줄임 (기여, 알림 규칙 담당) |
| 신입 온보딩 | 온보딩 문서와 실습 리포를 만들어 첫 PR까지 걸리는 기간을 3주에서 1주로 단축 |
| 레거시 개선 | 결제 모듈 테스트 커버리지 12%에서 68%로 올리고 장애 0건으로 마이그레이션 |

## 행동 동사 모음 (IT)

설계, 도입, 이전, 자동화, 단축, 절감, 통합, 분리, 표준화, 문서화, 측정, 제거, 재작성, 최적화, 주도, 조율

"최적화"는 무엇을 어떤 지표로 최적화했는지 같이 쓴다.
