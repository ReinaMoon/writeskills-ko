# 배치(메가) 모드

대주제 1 > 마스터 1 + 서브 노트 N.

## 6축 분해 (합 N, 기본 10)

| 축 | 권장 수 | 내용 |
|----|--------:|------|
| A 시장, 규모, 트렌드 | 1~2 | 규모, 성장, 플레이어 |
| B 카테고리, 지형 | 1~2 | 분류, 지도 |
| C 정의, 대상, 범위 | 1 | 개념, 타깃 |
| D 활용, 도구 | 3~4 | 시나리오, 대표 도구 |
| E 사례, 워크플로 | 1~2 | 실사용 |
| F 비용, ROI, 전망 | 1~2 | 가격, 효과, 전망 |

확정 전 폴더, 파일을 만들지 않는다.

## 파일

| 산출 | 패턴 |
|------|------|
| 마스터 | `{대주제}.md`: 개요, 체크박스 인덱스, 종합 시사점 |
| 서브 | `RL_{nn}_{짧은주제}.md` 또는 `R_{nn} {짧은주제}.md` |

마스터 인덱스 예:

```markdown
- [ ] 01. {제목} → [[RL_01_...]]
```

서브 작성 직후 `- [x]`로 갱신. 완료 시 종합 시사점(축별 1문단 + 활용 우선순위)과 `status: done`.

## 깊이

배치 전체에 basic 또는 deep 하나를 적용. 서브마다 깊이를 섞지 않는다(사용자가 명시하면 예외).
