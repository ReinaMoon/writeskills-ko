# 예시: 배치 모드 실패 분기

대주제: “팀 문서 도구 10종 비교”

| 상황 | 처리 |
|------|------|
| 서브 주제 3/10만 소스 A/B 확보 | 마스터에 `partial: 3/10` 표시. 완료분만 서브 노트. 나머지는 `blocked` + 필요 소스 |
| 한 서브만 C급 기사뿐 | 해당 서브에 `등급 부족` 표시. 단정 문장 금지 |
| 사용자가 중간에 주제 변경 | 마스터 인덱스만 갱신. 이전 서브는 `archived` |
| 웹 접근 실패 | 로컬/사용자 제공 자료만으로 채우고 missing에 URL 재시도 목록 |

마스터 노트 요지:

```markdown
# RL_마스터_팀문서도구
- 목표 서브: 10
- 완료: 3
- blocked: 7 (소스 부족)
- 다음: 사용자에게 A/B 소스 우선순위 확인
```
