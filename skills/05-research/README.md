# 05-research: 기술, 시장 조사

엔지니어링/제품 의사결정을 위한 조사 2스킬입니다.  
노트(`research-topic`)와 제출용 보고서(`research-report`)를 나눕니다.

## 스킬 목록

| 스킬 | 목적 | 언제 쓰나 | 예시 |
|------|------|-----------|------|
| [research-topic](./research-topic/SKILL.md) | 참조 노트 (기본/딥/배치) | 스택 비교, 트렌드, 다주제 배치 | `examples/batch-failure-modes.md` |
| [research-report](./research-report/SKILL.md) | 제출용 고정 절 보고서 | 팀/경영진 공유 문서 | `examples/sample-report.md` |

## 모드 (`research-topic`)

| 모드 | 산출 |
|------|------|
| 기본 | 노트 1, 소스 3~5 |
| 딥 | 노트 1, 소스 10+, 교차검증 |
| 배치 | 마스터 1 + 서브 N (서브 목록은 사용자 확정 후) |

## 체인

```
research-topic → research-report
```

강의 소재 → `lecture-research`, 책 카드 → `book-research`, 위키 raw → `wiki-research`.

- 실시간 뉴스 알림
