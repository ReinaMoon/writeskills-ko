# 예시: 제출용 조사 보고서 (요약본)

```markdown
# 팀 위키 도입 현황 조사

## 1. 요약
사내 3개 팀은 위키를 쓰지만 스키마가 달라 검색, 온보딩 비용이 크다. 공통 페이지 필드(요약, 소유, 갱신일) 표준화가 우선이다.

## 2. 범위
- 포함: 도구, 페이지 유형, 검색 불만
- 제외: 라이선스 가격 협상

## 3. 방법
인터뷰 5명, 공개 문서 8건. 조사일 2026-11-01~11-08.

## 4. 발견
1. 팀마다 라벨 체계가 다름
2. 상단 요약 없는 페이지가 과반
3. 런북과 설명 페이지가 혼재

## 5. 근거
| 발견 | 출처 | 등급 |
|------|------|------|
| 요약 없음 58% | 사내 샘플 40p 점검 | B |
| 검색 불만 | 인터뷰 노트 | C (보조) |

## 6. 한계
표본이 한 본부. 전사 일반화 보류.

## 7. 다음 조사
- 온콜 팀 런북 교차 점검
- 표준 필드 RFC 초안
```
