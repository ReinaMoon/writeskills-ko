# 씬 요청 정보 묶음

매 집필 요청에 아래를 채운다. 사용자에게 긴 프롬프트를 강요하지 말고, 스킬이 내부적으로 조합한다.

## 고정

- 서술 규칙(시점, 시제, 어미, 금지) 또는 `style-guide.md`
- 톤 앵커 문단 3~5 또는 가이드 샘플

## 가변

- 챕터 번호, 장소, 등장 인물
- 사건 요약, 감정 시작>끝
- 필수 요소 / 하지 말 것
- 직전 장면 마지막 2~3문단
- 등장 인물 카드만

## 이어쓰기

앞부분 원고 + 동일 고정 규칙 + "이어서 N자"

## 자가 점검 후 출력

대화 MD 기본. 파일은 `draft-ch{NN}.md`.
