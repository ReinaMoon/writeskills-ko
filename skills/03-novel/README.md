# 03-novel: 소설

소설을 쓰고 싶은 사람을 위한 스킬 4개입니다.  
퇴고는 `../02-book/book-editing` 소설 모드.

## 스킬 목록

| 스킬 | 목적 | 언제 쓰나 | 예시 |
|------|------|-----------|------|
| [novel-planning](./novel-planning/SKILL.md) | 소재, 장르, 인물, 플롯, 연재 회차표 | 본문 직행 금지, 설계 먼저 | `examples/one-page-premise.md` |
| [novel-voice](./novel-voice/SKILL.md) | 파일럿 → 문체 규약 | 톤/화법 고정 | `examples/voice-axes-sample.md` |
| [novel-writing](./novel-writing/SKILL.md) | 씬 집필 | 기획+보이스 이후 | `examples/scene-draft-short.md` |
| [novel-continuity](./novel-continuity/SKILL.md) | 인물/시간/소품 모순 점검 | 여러 챕터 이어 쓸 때 | `examples/contradiction-report.md` |

## 체인

```
novel-planning → novel-voice → novel-writing
  → novel-continuity → book-editing(소설 모드)
```

## 연재형

"웹소설", "연재", "회차"라고 하면 `novel-planning`이 3막 플롯을 회차표로 바꿉니다.  
회차당 사건 1개와 끝 훅 1개, 훅 유형(정보 공개, 위기 진입, 선택 강요, 반전, 감정 정점) 3회 연속 금지, 초반 3회 체크리스트가 들어 있습니다.  
특정 플랫폼 조회수 공식이 아니라 연재 일반 구조입니다. → `novel-planning/references/serial-format.md`  
10회마다 `novel-continuity`로 모순 점검을 권장합니다.

story-bible 스키마: `novel-continuity/references/story-bible.md`  
시리즈: `../00-core/handoff/series-schema.md`  
비평만: `../00-core/output/critique-only.md`

참조용으로 다른 작가 이름을 떠올려도, 그 문장을 복제하거나 가이드에 인용하지 않습니다.

## 이 카테고리 범위 밖

- 연재 플랫폼 조회수 최적화
- 특정 작가 문장 학습/복제 예시
