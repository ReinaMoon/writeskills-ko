# style-guide.md 슬롯

```markdown
# style-guide: {가제}

## 적용 작품
장르, 한 줄 전제

## 참조 방향
- 참고 작가: {이름} (형식 방향 참고점: 모사 아님)
- 핵심 주제 / 지배 정서

## 문체 7축 목표
- 문장 길이: …
- 시점, 거리: …
- 감각: 장면당 N채널, 우선 채널
- 대화:서술: …
- 리듬: …
- 종결, 시제: …
- 정서 온도: …

## 차용 / 유지 / 버림
- 차용: …
- 유지: …
- 버림: …

## 금지
- …
- 작가 문장 모사 금지

## 적용 샘플 (검증 통과본)
(150~250자)
```

진단값(현재)과 목표값(앞으로)을 구분한다. 추상어("잔잔하게") 대신 행동 가능 기준.
