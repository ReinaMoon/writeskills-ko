# 예시: 7축 진단 요약 (파일럿 기반)

| 축 | 관찰 | 목표 |
|----|------|------|
| 문장 길이 | 중문 위주, 단문 드묾 | 긴장 장면에서 단문 비율↑ |
| 시점, 거리 | 제한 3인칭, 주인공에 밀착 | 유지 |
| 감각 밀도 | 시각 편중 | 장면당 청각, 촉각 1회 이상 |
| 대화:서술 | 서술 70 | 갈등 장면에서 대화 비중↑ |
| 리듬 | 접속 남발 | 판단, 행동 문장 독립 |
| 종결, 어조 | 다체 | 유지 |
| 정서 온도 | 건조 | 유지 (서정 금지 목록에 추가) |

참조 작가명은 생략 가능. 있어도 가이드 본문에는 적지 않는다.
