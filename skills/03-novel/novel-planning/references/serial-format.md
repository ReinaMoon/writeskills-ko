# 연재형 기획

완결형 3막을 회차 단위로 쪼갤 때 쓰는 규칙입니다. 특정 플랫폼 조회수 공식이 아니라 연재 일반 구조입니다.

## 회차 설계

| 항목 | 기준 |
|------|------|
| 회차 분량 | 사용자 지정. 없으면 4,000~5,500자 |
| 회차당 사건 | 1개 (작은 사건이라도 상태 변화) |
| 회차 끝 | 훅 1개 |
| 아크 | 10~25회 단위 소목표 |

## 훅 유형

| 유형 | 설명 | 예 |
|------|------|----|
| 정보 공개 | 새 사실이 마지막 줄에 | "그 계약서의 서명은 아버지 것이었다." |
| 위기 진입 | 행동 직전에 끊기 | 문이 열리기 직전 |
| 선택 강요 | 두 길 중 하나를 고르기 직전 | |
| 반전 | 이전 회 해석을 뒤집기 | |
| 감정 정점 | 관계 변화 직후 | |

같은 유형 3회 연속 금지.

## 초반 3회 체크

- [ ] 1회 안에 주인공이 무엇을 원하는지 보인다
- [ ] 2회까지 그것을 막는 벽이 보인다
- [ ] 3회 끝에 돌아갈 수 없는 선택이 있다
- [ ] 설정 설명은 사건 안에서, 독백 설명 문단 2개 이하

## 회차표 형식

```markdown
| 회 | 사건 | 상태 변화 | 훅 유형 | 훅 문장 초안 |
|----|------|-----------|---------|--------------|
| 1 | | | | |
```

## 연속성

회차가 쌓이면 `novel-continuity`로 10회마다 모순 점검을 권장합니다.
