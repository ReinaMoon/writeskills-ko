# 본문 > 피치 매핑, 스토리라인

---

## 1. 절 > 슬라이드

| BP 절 | 슬라이드 |
|-------|----------|
| 문제 | 문제, 문제 규모 |
| 해결 | 개요, 작동 |
| 경쟁 | 차별 Compare |
| 시장 | 타깃, TAM/SAM/SOM |
| GTM, 모델 | 진입, 매출/단위경제 |
| 재무 | 자금 요약(선택) |
| 팀 | Team |
| 요약, 요청 | Cover 보조, Closing |

외부환경, 장기 인력계획 등은 피치에서 생략하거나 한 줄 흡수.

---

## 2. 패턴

### A: Problem-First

B2C, 사회문제. 문제>해결>시장>팀. 문제 장에 사례 보강.

### B: Traction-First

매출, 사용자, 도메인 경력이 있을 때. 팀/트랙션을 앞쪽으로.

### C: Market-First

B2B, 기술. 시장, 기술 우위를 앞쪽, 솔루션 분량 확대.

### 선택 트리

```
검증 데이터 있음? → B
일반 소비자, 공감형? → A
기업, 기술 우위? → C
```

---

## 3. 단독 모드 필수 6항

한 줄 정의 / 문제+규모 / 솔루션+작동 / 차별 3 / 시장 / 모델(+자금 요약). 
없으면 한 번에 모아 묻는다.
