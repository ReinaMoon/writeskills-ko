# 피치 스토리보드, 스펙 블록

---

## 1. 권장 장 구성 (디바이더 없음 기본)

| # | 유형 | 메시지 |
|---|------|--------|
| 1 | Cover | 사업명, 한 줄, 발표자 |
| 2 | Content | 문제 |
| 3 | Number | 문제 규모 |
| 4 | Content | 해결 개요 |
| 5 | Content | 작동 방식 |
| 6 | Compare | 차별점 |
| 7 | Content | 타깃 |
| 8 | Number | 시장 (TAM/SAM/SOM) |
| 9 | Content | GTM |
| 10 | Number | 모델, 트랙션 |
| 11 | Compare | 자금 요약 (선택) |
| 12 | Team | 팀 |
| 13 | Closing | 비전, 요청, 연락 |

디바이더는 선택. 5분 발표면 3, 5, 11 등을 흡수, 삭제.

---

## 2. MD 스펙 블록 예

```markdown
## S03 | Number | 문제 규모
- 메시지: …
- 대형 수치: …
- 근거: …
- 노트: (15~40초)
```

---

## 3. 점검

- 1장 1메시지 
- 글머리 ≤5 
- Cover, Closing 존재 
- 패턴(A/B/C)에 맞게 앞쪽 강조 장 배치
