# 피드 롱폼 안티패턴

초안, 리라이팅에서 같은 실수를 반복하지 않기 위한 짧은 대조표. 공통 금지어는 `../../../00-core/principles/writing-principles.md`가 우선한다.

## 1. 메타 서술 > 직접 진입

| 피할 것 | 방향 |
|---------|------|
| 오늘은 ~에 대해 이야기합니다 | 본론, 장면, 선언으로 바로 |
| 이번 글에서는 세 가지를 소개합니다 | 첫 항목부터 시작 |
| 지금부터 살펴보겠습니다 | 삭제 |

## 2. 과장, 모호 > 구체

| 피할 것 | 방향 |
|---------|------|
| 혁신적, 최고의, 완벽한 | 비교 기준, 수치, 결과 |
| 매우, 쉽게, 빠르게 | 시간, 단계, 조건 |
| ~할 수 있습니다 | 조건 + 단정, 또는 단정 |

## 3. 추상 > 행위

| 피할 것 | 방향 |
|---------|------|
| ~의 중요성/가능성 | 누가 무엇을 하는가 |
| 다양한 활용 | 구체 사용처 나열 |

## 4. 피드 특화

| 피할 것 | 방향 |
|---------|------|
| 접힘 전을 인사, 목차로 채움 | 갈등, 관찰, 질문, 실용 선언 |
| 본문 전체가 한 덩어리 | 2~3문장마다 행간 |
| 반응 장치 0개 + 반응 목표만 큼 | 질문, 선택지, 복사 실물 1개 |
| 알고리즘, 시간대 미신 문구 | 삭제 (플랫폼 중립) |
| 이모지, 기호 과다 | 구조 분리에만 최소 사용 |

## 5. 유형 불일치

| 증상 | 교정 |
|------|------|
| 관점형인데 목록만 | 판단 기준 문단 추가 |
| 실용형인데 철학만 | 복사 가능한 예시 필수 |
| 경험형인데 설교 | "좋더군요" 톤, 당위 삭제 |
