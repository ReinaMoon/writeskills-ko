# 예시: 훅 / 안티패턴

## 좋은 훅 (첫 3줄)

```
문서가 없어서 막힌 게 아니다.
결정이 문서에 안 적혀서 막힌다.
팀에서 같은 일 겪어본 사람?
```

## 안티패턴

| 안티패턴 | 왜 약한가 | 고치기 |
|----------|-----------|--------|
| “오늘은 팁 공유합니다!” | 갈등, 관찰 없음 | 구체 장면이나 문제로 시작 |
| 해시태그 나열로 시작 | 첫 화면 낭비 | 본문 뒤에만 |
| 동기부여 명언 | 실행 기준 없음 | 판단 기준 한 줄로 교체 |
| 플랫폼 알고리즘 자랑 | 채널 종속, 검증 불가 | 삭제 |
