# write-content 유형별 구조 슬롯

Step 2~3에서 사용한다. 슬롯 순서, 경계를 바꾸지 않는다. 원문 보존 모드에서는 원문 순서를 우선하고, 비어 있는 슬롯만 보강한다.

## 칼럼형

```
[도입] 현상 관찰 또는 통념 (1~2문단)
[전환] 문제 재정의: 통념이 흔들리는 지점 (1문단)
[기준] 새 판단 기준 + 근거/사례 1~2개 (2~3문단)
[마무리] 관점 재정렬: 요약이 아닌 질문, 기준의 이동 (1문단)
```

## 문서형

```
[서론] 배경, 맥락 + 이 글의 범위 (1~2문단)
[본론1] 핵심 개념/항목 + 판단 기준
[본론2] 적용, 사례, 데이터 + 해석
[본론3] 심화 또는 주의 (선택)
[결론] 핵심 요약 3문장 이내 + 다음 행동 1개
```

## 뉴스레터

```
[인사/도입] → [메인 1~2주제] → [부가] → [CTA + 다음 호 예고]
```

## 분석 기사

```
[도입 문제 재정의] → [판단 기준] → [메커니즘] → [사례] → [관점 재정렬]
```

## 보도자료

```
[리드 1문단: 누가, 무엇을, 언제, 어디서] → [사실 보강] → [인용 1~2] → [배경] → [문의]
```

사실과 의견을 섞지 않는다. 확인되지 않은 수치는 `[미확인]`.
