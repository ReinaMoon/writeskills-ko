# 시선 설계 도구

`write-essay` Step 2 전용. 시선을 정한 뒤에만 초안으로 간다.

## 시선 정의

소재를 보는 **각도, 거리, 태도**. 시선이 정해지면 쓸 것과 버릴 것이 갈린다.

형식:

```
[소재]를 통해, [무엇]을 [어떤 태도로] 본다.
```

예: "버린 책상을 통해, 무언가를 버릴 때 함께 버려지는 시간을 본다."

### 점검

- [ ] 소재와 보는 각도가 모두 들어 있는가
- [ ] 교훈, 당위("~해야 한다")가 없는가
- [ ] 한 문장으로 글의 방향이 그려지는가

## 시선 4축 (주 축 1개)

| 축 | 양극 | 짧은 가이드 |
|----|------|-------------|
| 거리 | 가까이 ↔ 멀리 | 단일 장면은 가까이, 누적 경험은 멀리 |
| 시간 | 그때 ↔ 지금 | 생생함은 그때, 낙차는 지금 |
| 초점 | 사물 ↔ 마음 | 마음은 사물에 닻을 둘 것 |
| 태도 | 받아들임 ↔ 의심 | 상실, 기억은 받아들임, 통념은 의심 |

## 시선 유형 6종

| 유형 | 작동 | 골격 비중 |
|------|------|-----------|
| 관찰자 | 장면의 결을 세밀히 | 진입, 전개 큼, 전환 작음 |
| 회고자 | 그때/지금 낙차 | 전환(시간 점프) 큼 |
| 질문자 | 답을 유보한 채 물음 | 여운(열린 질문) 큼 |
| 대조자 | 두 장면, 시점 병렬 | 전개가 둘로 갈림 |
| 동행자 | 관계의 옆걸음 | 전개에 관계 움직임 |
| 발견자 | 사소함에서 의외 | 전환(발견 순간) 집중 |

기본 골격: `[진입] > [전개] > [전환] > [여운]`

## 실패 교정

| 실패 | 교정 |
|------|------|
| 시선 없음(소재 나열) | 주 축 1개 강제 |
| 시선이 둘 이상 | 주 시선 하나로 고정 |
| 시선이 주장 | 당위 삭제, 각도만 남김 |
| 시선이 추상 | 구체 사물에 닻 |
