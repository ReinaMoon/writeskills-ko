# write-essay

시선 산문. 논증 슬롯 없음.

칼럼=납득, 기준 / 에세이=공명, 여운.

## 코어 참조

필수:
- `../../00-core/style/mystyle-gate.md`
- `../../00-core/principles/writing-principles.md`
- `../../00-core/style/tone-matrix.md`

선택: `korean-prose-rules`, `quality-gates`. 상세: `../../00-core/routing/core-ref-diet.md`
예시: `examples/essay-vs-content.md`

## 입력

| 입력 | 필수 | 설명 |
|------|:----:|------|
| 소재, 이유 | O | |
| 정서, 분량 | 권장/선택 | |
| 메모 | 선택 | 3문장+ 보존 |

추상 소재는 장면화 후 Step2.

## 워크플로

1→5 (G0~G4). 2: 시선 1문장, `gaze-design.md`. 교훈, 당위면 write-content (G1).
3: 슬롯 소제목 금지. 4: 시선→장면→여운 (G3). 5: 암시 제목, `final.md`.

모드: 보존/신규. 단상 R1~R4 6~12문장→피드 목표면 `write-social`.

## 초안

첫 문장 장면. 감정은 보여주기. 1인칭. 마무리 잔상. 금지: "결국", "~해야", CTA, 3가지 이유.

## 출력

S2: 시선, 유형, 진입/전개/전환/여운. S4: 시선, 장면, 문장, 여운 점검.

## 규칙

- 기준, CTA 강제 금지.
- `다`/`합니다` 통일.
- 검색형 제목 금지.

## 완성 조건

- [ ] 시선 관통
- [ ] 전환 존재
- [ ] 여운 마무리
- [ ] 논증 없음
