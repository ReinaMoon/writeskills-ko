# 예시: 에세이 vs 칼럼(`write-content`) 경계

| | `write-essay` | `write-content` |
|--|---------------|-----------------|
| 목적 | 시선, 공명 | 관점, 기준 이동, 설득 |
| 도입 | 장면 | 통념, 문제 정의 |
| 본문 | 관찰이 쌓임 | 근거→판단 |
| 마무리 | 여운 | 기준 재정렬 |
| 맞는지 테스트 | “그래서 뭘 하라”가 없어도 됨 | “무엇을 기준으로 고르나”가 남아야 함 |

같은 소재 “야간 배포”:

- 에세이: 서버실 불빛, 닫지 못한 노트북, 말없이 남은 체크리스트
- 칼럼: 야간 배포가 습관이 된 팀의 문제 정의와, 창 제한을 기준으로 삼는 이유
