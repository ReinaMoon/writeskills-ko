# 블로그 유형별 H2/H3 구조

소제목은 기능명, 명사 나열이 아니라 **판단, 행동, 질문**으로 쓴다. H2 2~5개, H3는 H2당 0~3개.

## 방법론 해설

```
[도입] 현상 + 판단 선언
## 개념: 무엇이며 왜 다시 정의하는가
## 단계별 실행
### 원칙 1: 판단 기준 + 실행
### 원칙 2
### 원칙 3
## 흔한 오해와 주의
[마무리] 핵심 기준 압축
```

## 가이드, 튜토리얼

```
[도입] 이 가이드가 필요한 구체 상황
## 전제, 준비
## 단계별 실행
### 단계 n: 행동 + 기대 결과
## 자주 막히는 지점
[마무리] 실행 기준 정리
```

## 도구, 리뷰

```
[도입] 검토 이유(문제 상황)
## 평가 기준과 핵심 기능
### 기능별 결과
## 기존 도구와의 차이
## 언제 고를까
[마무리] 선택 기준
```

## 인사이트, 관점

```
[도입] 현상 + 반론
## 기존 관점의 한계
## 기준을 바꾸면 보이는 것
## 적용하면 달라지는 점
[마무리] 독자가 가져갈 기준
```

## 경험 기반

```
[도입] 구체 장면
## 경험에서 발견한 것
## 기준이 바뀐 지점
[마무리] 남기는 판단 기준
```

분량 가이드: 공백 포함 1,200~2,500자 (±20%).
