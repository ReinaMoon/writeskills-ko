# 예시: 일반 검색 블로그 골격 (포털 비종속)

주제: “배포 전 체크리스트”

## 검색 의도
- 주 키워드: 배포 체크리스트
- 독자: 주니어 백엔드
- 이 글이 답하는 질문: 배포 직전 무엇을 확인하나

## 목차 (H2/H3)

1. 이 글에서 다루는 범위 / 다루지 않는 것
2. 배포 전 체크리스트 5항목
 - 헬스, 메트릭
 - 롤백 경로
 - 권한, 시크릿
 - 의존 서비스
 - 공지 채널
3. 15분 타임박스 예시
4. 다음에 읽을 글 (내부 링크 2개)

## 메타
- 제목 후보: `배포 전 체크리스트 5가지`, `롤백까지 포함한 배포 점검`
- 설명: 배포 직전 확인 항목을 5개로 정리한다. 인프라 설계는 다루지 않는다.
- 내부 링크: 런북 작성법, 카나리 배포 개요
