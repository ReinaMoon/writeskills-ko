# edit-de-ai

의미는 유지, 말투만 바꾼다. 사실 추가 금지.

## 코어 참조

필수: `../../00-core/principles/ai-tone-patterns.md`, `../../00-core/principles/korean-prose-rules.md`  
선택: `../../00-core/style/mystyle-gate.md` (mystyle 있으면 우선)  
예시: `examples/before-after-blog.md`

## 입력

원문(필수), 장르(블로그|업무|에세이|자소서), 어미(합니다|해요|한다), 강도(가볍게|기본|과감).

## 모드

| 모드 | 신호 | 산출 |
|------|------|------|
| 진단 | 진단만, 리뷰만 | 판정 표 + 밀도 점수 (`critique-only`) |
| 기본 | 기본값 | 판정 표 상위 10개 + 수정본 |
| 과감 | 과감, 다시 써 | 구조 패턴(T)까지 재배치 |

## 워크플로

1. 문단별 패턴 ID 태깅. 밀도 계산.
2. V, S, K 먼저. T는 과감 모드만.
3. 수정본 작성. 원문 수치, 고유명사, 링크 보존.
4. 근거 없는 일반론은 지우거나 `[근거 필요]`.
5. 전후 밀도 비교 한 줄.

## 출력

```markdown
## 진단 (밀도 1.4 → 0.3)
| ID | 위치 | 원문 | 수정 |
## 수정본
## 남은 확인
- [근거 필요] 2곳
```

## 규칙

- 없는 경험, 수치, 사례 창작 금지.
- 말투를 바꾸려고 사투리, 유행어 넣지 않음.
- 길이는 원문 대비 70~110%.
- 긴 대시, 세미콜론, 이모지 머리표 제거.

## 완성

밀도 0.5 이하, 의미 보존, 사실 추가 없음, 어미 통일
