# 예시: 사내 공지 교정

## 원문

> 이번 배포를 통해 어플리케이션의 성능 개선이 이루어졌습니다. 몇일 내로 메세지 큐 설정을 변경할 예정이니 참고 부탁드립니다. 문제가 발생할 경우에는 `#ops` 채널로 연락주시면 되요.
