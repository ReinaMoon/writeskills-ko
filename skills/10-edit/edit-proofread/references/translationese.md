# 번역투 교정

영어 문장 구조를 그대로 옮긴 표현입니다. 의미가 같으면 짧은 쪽을 씁니다.

| 번역투 | 자연스러운 표현 |
|--------|-----------------|
| ~를 가지고 있다 (have) | ~가 있다 |
| ~에 의해 수행된다 | ~가 한다 |
| ~하는 것이 가능하다 | ~할 수 있다 |
| ~에 있어서 | ~에서, ~할 때 |
| ~을 통해 (through) | ~로, ~해서 |
| 그것은 ~이다 (It is) | 주어 생략 |
| ~함에 따라 | ~하면서 |
| 많은 수의 | 많은 |
| ~하는 경향이 있다 | 자주 ~한다 |
| ~로 인하여 | ~ 때문에 |
| 가장 ~한 것 중 하나 (one of the most) | 손꼽히는, 대표적인 |
| ~의 경우에는 | ~는 |
| 만들어 내다 (create) 과다 | 만들다 |
| 제공하다 (provide) 과다 | 주다, 있다 |
| ~할 필요가 있다 | ~해야 한다 |
| 진행하다 남발 (회의를 진행하다) | 회의하다 |

## 판단 기준

1. 주어가 사람이면 능동으로.
2. 조사 "의"가 한 구에 2번 이상이면 줄인다.
3. 법률, 계약, 사양서처럼 정확성이 중요한 문서는 번역투라도 의미가 명확하면 둔다. `판단 보류`로 표시.
