## 띄어쓰기

| 틀림 | 맞음 |
|------|------|
| 할수있다 | 할 수 있다 |
| 그런데도 불구하고 | 그런데도 (중복) |
| 3개월간 / 3개월 간 | 3개월간 (접미사 붙임) |
| 데이터베이스를 사용할때 | 사용할 때 |
| 한번 (횟수) | 한 번 |
| 한번 (시도) | 한번 해 보다 |
| 해보다 | 해 보다 (붙임도 허용, 문서 안에서 통일) |
