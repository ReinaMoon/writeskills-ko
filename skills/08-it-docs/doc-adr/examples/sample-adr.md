# ADR-0012: 카나리 기본 비율 5%

- 상태: accepted
- 날짜: 2026-11-01
- 결정자: platform

## Context
전면 배포 사고 후 롤백 시간이 길어짐. 트래픽 일부를 먼저 검증할 필요가 있음.

## Options
| 옵션 | 요약 | 기각한 비용 |
|------|------|-------------|
| A 5% 카나리 | 관측 창 15분 | 배포 파이프 변경 |
| B 블루그린만 | 단순 | 비용·용량 |

## Decision
A. 기본 5%, 헬스+에러율 게이트 통과 후 100%.

## Consequences
- 득: 조기 감지
- 실: 파이프 복잡도
- 후속: doc-runbook 카나리 롤백
