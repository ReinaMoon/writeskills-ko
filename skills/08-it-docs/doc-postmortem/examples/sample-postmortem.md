## 원인
### 트리거
정산 배치의 조건절 누락으로 주문 테이블 전체 스캔.
### 근본 원인 (5 Whys)
1. 왜 API가 느렸나? → DB CPU 포화
2. 왜 포화됐나? → 배치가 전체 스캔
3. 왜 전체 스캔이 배포됐나? → 배치 쿼리는 리뷰 시 실행 계획 확인 대상이 아니었음
4. 왜 대상이 아니었나? → 배치는 API와 다른 저장소라 DB 리뷰 체크리스트가 적용되지 않음
5. 왜 다른가? → 배치 저장소 생성 시 공통 CI 템플릿을 쓰지 않음
### 기여 요인
