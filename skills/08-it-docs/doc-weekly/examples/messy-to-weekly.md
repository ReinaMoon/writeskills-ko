# 예시: 지저분한 메모 → 주간 보고

## 입력 (메모)

```
- api 배포 완료
- 다음주 대시보드
- 결제 타임아웃 이슈 아직
- 민수랑 온콜 로테이션 얘기함
- 문서 정리 좀 함
- 부하테스트는 못함 의존 스테이징 다운
```

## 출력

```markdown
# 2026-11-03 ~ 11-09 주간 업무 보고

## 1. 이번 주 한 일
- API 배포 완료
- 온콜 로테이션 합의 (민수)
- 운영 문서 일부 정리

## 2. 다음 주 할 일
1. 결제 타임아웃 원인 조사 (우선)
2. 대시보드 초안
3. 부하테스트 (스테이징 복구 후)

## 3. 이슈, 리스크
- 결제 타임아웃 미해결
- 스테이징 다운으로 부하테스트 지연

## 4. 특이사항
- 없음
```
