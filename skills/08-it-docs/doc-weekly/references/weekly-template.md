# 주간 보고 템플릿, 분류 가이드

`doc-weekly` Step 1~3에서 사용한다.

## 시제, 상태 판별

| 메모 단서 | 배치 |
|-----------|------|
| 완료, 배포함, 머지됨, 종료 | §1 한 일 |
| 진행 중, N%, WIP | §1에 `진행 중(N%)` 또는 §2로 이월 |
| 예정, 계획, 다음 주, TODO | §2 할 일 |
| 블로커, 지연, 의존, 리스크 | §3 이슈, 리스크 |
| 휴가, 조직 공지, 칭찬, 공유 | §4 특이사항 |

## 우선순위 (할 일)

1. 외부 기한, 고객 영향
2. 다른 사람/팀에 의존되는 산출물
3. 기술 부채, 내부 개선

## 최소 예시 (구조만)

```markdown
# 2026-11-03 ~ 11-07 주간 업무 보고

## 1. 이번 주 한 일
- 결제 API 타임아웃 5초 반영 및 배포
- 온콜 런북 롤백 절 초안 작성 (진행 중 80%)

## 2. 다음 주 할 일
- 서킷브레이커 PoC 범위 합의
- 스테이징 부하 테스트 시나리오 확정

## 3. 이슈, 리스크
- 스테이징 DB 스냅샷 지연 → SRE 슬롯 필요

## 4. 특이사항
- 11-11 오후 반차
```

## 파일명

`weekly-YYYY-MM-DD.md` (주의 시작일 또는 작성일)
