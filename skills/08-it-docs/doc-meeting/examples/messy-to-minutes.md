# 예시: 전사 조각 → 회의록

## 입력

```
어제 거 어때요? 아 배포 화요일로 하죠. 민수가 롤백 스크립트 확인한대요.
대시보드는 아직... 지영이 금요일까지 초안?
아 그리고 알림 채널 슬랙 #ops로. 그건 결정인 거죠? 네.
점심 뭐 먹지 (잡담)
```

## 출력

```markdown
# 2026-11-10 배포 점검 회의

## 개요
- 일시: 2026-11-10 (입력에 시각 없음 → TBD)
- 참석: 민수, 지영, (사회자 미기재)
- 안건: 배포 일정, 롤백, 대시보드, 알림

## 결정
- 배포일: 화요일
- 알림 채널: Slack `#ops`

## 액션
| 할 일 | 담당 | 기한 |
|------|------|------|
| 롤백 스크립트 확인 | 민수 | TBD |
| 대시보드 초안 | 지영 | 금요일 |

## 논의 메모
- 대시보드 범위는 미확정
```
