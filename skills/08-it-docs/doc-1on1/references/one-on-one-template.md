# 1:1 노트 템플릿, 민감도 가이드

`doc-1on1`에서 사용한다.

## 공개 범위

| 값 | 의미 | 올릴 수 있는 곳 |
|----|------|-----------------|
| `private` | 당사자만 | 개인 노트, 암호화된 매니저 노트 |
| `manager-shared` | 매니저 체인 | HR 시스템, 매니저 폴더 (팀 채널 금지) |
| `team-safe` | 팀 공유 가능 | 위키, 채널 (합의된 액션, 목표만) |

기본값: `private`.

## 민감 라벨

본문에서 아래는 `🔒`를 붙이거나 §를 분리한다.

- 보상, 승진, 성과등급
- 건강, 개인 사정
- 동료에 대한 갈등 (이름 최소화, 행동만)
- 퇴사, 이직 의사

team-safe 출력 요청 시 🔒 절은 제거하고 합의 액션, 공개 목표만 남긴다.

## 피드백 작성

- **관찰 > 영향 > 요청** 순을 권장한다.
- "항상/절대" 같은 절대어를 쓰지 않는다.
- 칭찬도 구체 사례 한 줄을 붙인다.

## 지난 액션 점검

입력이 있으면 상단에 짧게:

```markdown
## 0. 지난 액션 점검
| 항목 | 상태 | 메모 |
|------|------|------|
| … | 완료 / 이월 / 취소 | |
```

## 파일명

`1on1-{멤버slug}-YYYY-MM-DD.md`
