# 예시: 1:1 노트

## 입력
멤버가 “배포 부담이 크다, 성장 과제로 온콜을 해보고 싶다”고 말함. 매니저는 이번 분기 목표 점검.

## 출력 (요지)

```markdown
# 2026-11-10 1:1 : 지영 / 민수
민감도: private

## 안건
- 멤버: 배포 부담, 온콜 경험
- 매니저: Q4 목표 중간 점검

## 피드백, 관찰
- 배포 야간 창이 연속되며 피로 호소
- 온콜 의지는 있으나 런북 숙지가 선행 조건

## 합의 액션
| 액션 | 담당 | 기한 | 다음 점검 |
|------|------|------|-----------|
| 런북 2건 페어 리뷰 | 지영+민수 | 11-17 | 다음 1:1 |
| 온콜 섀도 1회 배정 | 민수 | 11-24 | 다음 1:1 |
```
