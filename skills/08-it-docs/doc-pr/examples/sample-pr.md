# 예시: PR 본문

## 제목
주문 취소 시 사용한 쿠폰이 복구되지 않던 문제 수정

## 왜
부분 취소 경로에서 쿠폰 복구 호출이 빠져 있었습니다. 지난주 CS 문의 14건이 같은 원인입니다. (Refs #482)

## 무엇이 바뀌나
- `OrderCancelService.cancelPartial()`에서 쿠폰 복구를 전체 취소와 같은 메서드로 호출
- 쿠폰 복구를 트랜잭션 안으로 이동
- 이미 복구된 쿠폰은 건너뛰는 멱등 처리 추가

## 검증
- 단위 테스트 3개 추가 (부분 취소, 전체 취소, 중복 취소)
- 스테이징에서 부분 취소 시나리오 수동 확인 [첨부]

## 위험, 롤백
- 위험: 쿠폰 테이블 쓰기가 취소 트랜잭션에 들어가 잠금 시간이 약간 늘어남
- 롤백: 이 PR revert로 충분, 데이터 마이그레이션 없음

## 리뷰 순서
1. `OrderCancelService.java` (핵심)
2. `CouponRestoreService.java` (멱등 처리)
3. 테스트

## 커밋 메시지 (commit 모드 출력)

```
fix(order): 부분 취소 시 쿠폰 복구 누락 수정

부분 취소 경로가 쿠폰 복구를 호출하지 않아 사용한 쿠폰이 사라졌다.
전체 취소와 같은 복구 메서드를 쓰고 멱등 처리를 추가한다.

Refs #482
```
