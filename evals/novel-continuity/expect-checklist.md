# E6 expect-checklist (수동 판정표)

사람이 산출을 보고 항목마다 합격/불합격과 짧은 메모를 남긴다.  
자동 테스트가 아니다.

실행 경로 예: Claude Skills/Project, 또는 ChatGPT Custom GPT / Project

---

## A. 인물/소품 모순 (열쇠)

- [ ] Mira가 ch3에서 자기 소매의 brass key로 cellar를 연 것을 **모순으로 보고**했다
- [ ] 자동으로 원고를 고쳐 쓰지 않았다 (critique)
- [ ] High를 준 경우: **fatal 근거**가 있다 (탈출의 전제가 Mira 열쇠 소유인데 ch2에서 Jonah에게 넘김 → 인과 붕괴). Mid만 주고 fatal을 무시하면 이 fixture 기준으로는 약함
- [ ] fixture가 기대하는 High 이유(탈출 전제 붕괴)를 산출 또는 메모에 연결할 수 있다

실패 예: 모순을 못 봄 / 즉시 개작 / 모순이 아닌데 High

## B. 연도/나이

- [ ] Jonah “sixteen” (2000년, 생년 1986, 만 나이)를 **모순 또는 확인 필요**로 다뤘다 (만 나이면 약 14)
- [ ] 작품 달력/만 나이를 무시하고 세는나이로 덮어쓰지 않았다
- [ ] 등급은 영향도로 설명 가능하면 됨 (반드시 High일 필요는 없음)

## C. 미회수/회수 예정 복선

- [ ] F2(unsigned letter / cellar stairs)를 **오류(High 모순)로 올리지 않았다**
- [ ] 추적 표에서 `심음` 또는 `회수 예정` / planted / payoff planned 로 남겼다

## D. 회수 완료 복선

- [ ] F1(cracked pocket watch)를 회수 완료 / paid off 쪽으로 분류했다
- [ ] 회수됐다는 이유만으로 새 High 모순을 만들지 않았다

## E. 새 설정 발명 금지

- [ ] ch3의 map 장면에서 **새 세계관/훈련 이력을 지어내지 않았다**
- [ ] 한다면 원고 근거 부족 + 후보 위치만 (예: 앞 챕터에 지도 학습 장면 없음)

## F. 제공 범위 밖

- [ ] ch4 이후 회수 여부를 실패(High)로 단정하지 않았다
- [ ] “확인 불가” 또는 범위 밖 표시가 있다 (해당 시)

## G. 영어 문법 비대상

- [ ] 맞춤법/관사/어색한 영어를 연속성 리포트의 주 작업으로 삼지 않았다
- [ ] 문법 교정문으로 벗어나지 않았다
