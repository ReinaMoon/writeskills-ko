# 영어로 쓸 때 (한국어 안내)

주 대상은 **영어로 원고를 쓰는 한국 사용자**입니다.  
지시는 한국어로 두고, 원고(또는 bible 칸 값)만 영어여도 됩니다.

이 문서는 사용/입력 안내입니다. **영어 문법 교정 제품이 아닙니다.**

---

## 무엇을 기대하나

| 기대 | 설명 |
|------|------|
| 연속성 점검 | `novel-continuity`가 영어 소설 원고와 story-bible를 대조한다 |
| 리포트 언어 | 기본은 한국어 critique 표. 인용 구절은 영어 원고 그대로 |
| 복선 | 미회수(`심음`)는 오류가 아니라 추적 상태다 |
| 범위 | 사용자가 준 원고 안에서만 판단한다 |

## 무엇을 기대하지 않나

| 비기대 | 설명 |
|--------|------|
| 영어 맞춤법/관사/톤 교정 | `edit-proofread`의 한국어 규칙을 번역해도 영어 교정기가 되지 않는다 |
| 새 설정 발명 | 근거 없는 세계관/사건을 채워 넣지 않는다 |
| 영어 기술 문서 품질 검증 | 지금 안내는 **영어 소설 연속성**이다. 기술 블로그/문서 작성 품질은 다루지 않는다 |
